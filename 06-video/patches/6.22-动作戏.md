## 6.22 动作戏（打戏）写法：角色动作档案 + 因果交锋 + 失败诊断（补 6.0【四】第 3 条）【外部·可直接用】

**用法**：6.0【四】第 3 条要求“复杂动作保留准备、发力、接触和收束过程，不把多个动作挤在一个瞬间”，打戏、追逐、对抗是最容易出问题的地方。这条把它讲细了：先给每个角色定动作档案，再让每一轮交锋写清“谁打、打哪、结果、对方怎么回应、位置怎么变”，出片失败时按症状只改一类变量。可以在有打戏的段落补进 6.0。

**来源**：[irenerachel/fight-prompt-director](https://github.com/irenerachel/fight-prompt-director) SKILL.md、references/fight-design.md、diagnostics.md，MIT（11/07 整理人新增到收集页面）。摘编：去掉了首尾帧、参考视频、三套强度方案和极速版等和 6.0 生产方式不符的部分（6.0 全靠文字衔接、素材直接关联）。

**提示词正文**：

```
这一段有动作戏（打斗、追逐、对抗）时，按以下规则写。

【一、先给每个参战角色定动作档案】
优势距离；起手姿态；移动方式；主要攻击方式；防守与反制习惯；武器、弹药或能量资源；力量节奏；结束战斗的方式。
不同角色至少在距离、移动和反制方式上明显不同。远程角色要管视线、弹道和资源；近战角色要说明怎么缩短距离；体型差异要体现在速度、受力和环境反馈上。

【二、先写完成条件】怎样算结束：击倒、逼退、脱离、抵达、保护、拖延或撑到结束。再写各方怎么实现、对方怎么阻止。已经定好的胜负、对白、关键招式和结尾完整保留。

【三、每一轮交锋写六项】
谁发起；指向哪里；接触、格挡还是落空；对方怎么回应；双方位置怎么变；什么状态引出下一拍。
下一拍可以由距离变化、失衡、遮挡、资源消耗、场景损伤或暴露的空当触发。不要让双方同时做互不相关的动作。
重要命中写清：发力方向、接触位置、受力方向、位移结果、环境反馈。环境变化（碎片、裂痕、倒下的物件）要延续到后面的镜头。

【四、按参战主体选骨架】
- 单人突围：建立路线和出口 → 第一种威胁迫使改变步法或高度 → 第二种威胁封住原路，利用环境开新路 → 最后障碍检验前面建立的能力 → 抵达或停在清楚的位置。
- 双人攻防：双方不同的优势距离 → 一方迫使另一方离开舒适距离 → 被压制者用地形、武器或假动作扭转 → 交换位置或朝向 → 结束时明确谁取得空间或时间优势。
- 一人对多人：全景交代主角和每个对手的位置 → 对手从不同方向、不同节奏进攻 → 主角利用一个对手的位移挡住另一个 → 已经退出战斗的人和物保留在画面里 → 结尾明确剩余人数和主角去向。
- 人与巨兽：建立体型比例和安全距离 → 巨兽一次大范围动作改变地面或遮挡 → 主角从侧翼、高处或弱点取得短暂机会 → 巨兽调整攻击形成反转 → 结果用倒塌、退让、脱离或环境变化呈现。

【五、时长分配】
4~8 秒：一个完整动作闭环，最多一次明显转折；
9~18 秒：起动、争夺、反制、结果四到五个阶段；
19~30 秒：拆成五到七段，中段安排一次有效反转。
接触点太多时拆成几段，每段记录位置、朝向、武器、速度和场景损伤。

【六、镜头】每个镜头只承担一个主要职责：建立空间、跟随位移、看清接触、表达失衡或揭示结果。写清景别、机位、速度、方向和跟随对象。不用运镜挡住动作。

【七、硬规则】不用“激烈”“震撼”这类空泛强度词代替看得见的动作、方向和结果；武器、投射物、角色数量、场景损伤在切镜后不能自动重置；默认无字幕、无水印，不加没要求的旁白。
结尾写明：角色数量、武器数量、空间方向、资源状态、场景损伤。

【八、出片失败时】先找最影响观看的一个症状，每轮只改动作、镜头中的一类：
双方各打各的 → 补全发起、接触、回应、位移和下一拍；
接触点看不清 → 改用侧向中景或短促接触特写；
人物左右互换 → 固定轴线和屏幕方向，切镜前记录站位；
受击没有力量 → 写清接触部位、受力方向、位移和材质反馈；
远程攻击凭空出现 → 补充取用、装填或充能，交代路径和落点；
场景损伤恢复 → 在后面的时间段重复写损伤状态；
镜头随机跳切 → 减少机位，每镜只承担一个职责；
特效没有来源 → 删掉特效，或绑定到武器、装置、能力和接触点。
连续两轮没有改善，重新检查是不是分错了变量，不要一次重写全部。
```
