## 3.12 对白诊断：车轱辘话判断【外部·可直接用】

> **实测（11/03 第二轮）：已用于生产。** 已并进 6.0。

**用法**：一场戏成立，但台词来回绕、原地打转时用。它的价值在于分清「该删的重复」和「该留的重复」，不会把所有直白、喊满的台词都当成坏台词删掉。和 3.3 的区别：3.3 按七个维度重构台词，这条专门判断哪些台词在空转。

**来源**：[艾玛短剧 · 编剧 Skills](https://github.com/adoria111/emma-screenwriting-skills) skills/em-dialogue，MIT（收集页面）。摘编。

**注意和 1.0 的一处差别**：原技能默认把同一角色中间没被打断的连续几句合成一段、只写一次人名；1.0 的 3.1 要求每次台词换行都重新标注括号。用的时候按我们 1.0 的格式来，提示词里已经写明。

**提示词正文**：

```
请诊断这场戏的对白（只诊断，先不要给完整改写稿；我确认后再改）。

【三个判断问题】每句台词都问：
- 特定性：这个人为什么此刻对这个对象说这句？
- 目的性：他希望对方听完怎么回应？
- 必要性：删掉会损失什么信息、关系变化或情绪体验？

【车轱辘话的定义】不是字面重复，而是：同一信息或态度 + 同一策略 + 同一力度 + 没有新的剧情、情绪、关系或表演后果 = 戏原地不动。

【分别判断三种作用】（不要求每句三样都有）
- 剧情作用：新信息、新筹码、新策略、新决定或新后果；
- 情绪作用：蓄压、释放、宣判、站队、替观众出气、关系结算；
- 表演作用：爆发、停顿、反转、崩溃、冷下来决裂、类型卡点。

【直白喊情绪的台词分三种】
- 有效爆发：第一次公开反抗、情绪结算、划清阵营，并且改变了关系或行动——保留；
- 纯宣泄：没有新信息，但承担唯一的情绪峰值或演员爆点——保留核心句，检查后面是否需要落到行动上；
- 无效空喊：没有铺垫、不是新的情绪阶段、对方可以原样回嘴、没有后果——删除、合并或挪到真正的峰值。

【步骤】
1. 先概括场景契约：谁为了什么对谁说话、对方怎么抵抗、这场戏最终改变了什么；列出必须保留的事实、动作、关系、情绪节点和结尾。
2. 把同功能、同力度的请求、拒绝、指责、威胁、背景复述归成一组，指出它为什么停滞。
3. 目的相同但策略、压力、意义发生变化的重复要保留，说明它带来了什么新作用。
4. 改写时让每一轮回应上一轮、并给下一轮制造新麻烦（新筹码、反制、被迫选择或具体代价）；背景信息要作为冲突的武器出现，不要让人物停下来念履历。

【不能做】不新增事实、伤害、证据或往事；不把所有人改成同一种简短、会说金句的声音；不把所有高强度表达都降成克制冷感；不删掉让背叛、拒绝、动手成立的情绪台阶。

【括号提示】只在会改变一句话读法的地方加（哭腔、强压怒火、讥讽、哀求、突然转冷等），平铺直叙或紧邻动作已经说明白的不加。格式按我们的规范：每次台词换行都重新标注括号。

【输出】场景契约 / 重复链（哪几句、为什么停滞）/ 应保留的重复及理由 / 优先修改建议。
```
