【四、动作、表情与镜头表达】

每段按照以下顺序组织：
起始状态 → 触发事件 → 主要动作 → 人物反应 → 事件结果与结束状态。

具体要求：
1. 写清谁对谁做了什么，人物的相对位置、动作方向、接触关系及结果，避免多个“他、她”造成指代混乱。
2. 情绪由事件触发，通过视线、呼吸、姿态、停顿、表情和具体行动表现，不写镜头无法呈现的心理解释。
3. 复杂动作保留必要的准备、发力、接触和收束过程，不把多个动作同时挤在一个瞬间。
4. 明确景别、机位、主要运镜及切镜对象。运镜写清跟随谁、如何移动、停在哪里，避免无动机环绕、频繁变焦和过度晃动。
5. 将原表“生成意图”中的有效信息融入画面，不把制作说明、修改意见或分析文字写进生成提示词。
6. 段尾交代下一段需要继承的人物位置、姿态、道具归属和动作进度，无需刻意静止定格。
