## 6.23 切镜与跨段衔接检查：状态继承 + 台词跨镜 + 背景人物（补 6.0【五】【六】）【外部·可直接用】

**用法**：6.0【五】要求“已经完成的动作不重演、切镜不让人物重新入场、保持人物状态和道具归属一致”，这条给了逐镜逐段的检查顺序。特别有用的三点：上一段的最后一镜和下一段的第一镜要对得上；一句台词跨镜头时声音不能断、不能重新起句；画面里的背景人物不能“木站”，也不能抢戏或提前反应。适合 6.0 输出后、提交生成前检查。

**来源**：[djyy1031/ai-comic-drama-director-skills](https://github.com/djyy1031/ai-comic-drama-director-skills) skills/ai-shot-execution-continuity/SKILL.md，MIT（11/07 整理人新增到收集页面）。摘编：原技能面向“剧本 + 已有素材 → Seedance 分镜组”，和我们的生产方式接近；去掉了站位图、校验脚本和素材文件核对的部分。

**提示词正文**：

```
输出视频提示词后，按以下顺序逐镜、逐段检查。发现问题写出具体位置、证据、影响和最小修改，不要只写“连续性不好”。

1. 当前镜头只写本镜实际看得见、发出声音或直接起作用的人物、场景和道具。删掉上一镜遗留的内容、场号、旧提示词，以及“同前”“同上”这类模型看不到的上下文。
2. 第一帧：写明有效主体、动作状态、人物关系和画面目的。除非剧本要求空镜或延迟揭示，不用没有人物、没有信息的空镜开场；第一帧直接处在当前动作里，不加没内容的前摇。
3. 空间与全员表演：每个画面里的人物都要有位置、朝向、视线目标、和地标的距离、移动方向。不用“附近、旁边、看着对方”代替。画面里的每个人都要有当下的表演和剧情依据，包括背景人物；背景人物可以用低强度的视线、呼吸、姿态或生活动作，但不能抢主体、整齐划一地复制动作，或者提前反应。
4. 摄影机：写明在轴线哪一侧、朝向、高度、距离、主要运动、停在哪里、最后焦点在哪。一个镜头只保留一个主要运镜；必须越轴时在画面里重新建立方向。
5. 道具与手：记录持有者、左手还是右手、接触点、开合、损耗和使用结果。切镜后不能换手、复原、消失或无故新增。
6. 光线与物理：锁定主光来源和方向；动作检查重力、质量、惯性、摩擦、接触和环境反馈。
7. 台词：第一句由镜内看得见的动作或现场事件触发；一句台词跨镜头时，后一镜从第 0 秒接着说，不重复起句、不换说话人、不重新换气、不凭空停顿。切到听者或环境细节时，说话者可以作为画外声继续。一句完整的台词默认不跨段。
8. 切镜继承：逐对比较前一镜结束和后一镜开始的状态——人物、道具、环境、摄影机方向、台词。状态变化必须由镜内看得见的动作或明确的时间经过造成。
9. 跨段继承：上一段最后一镜到下一段第一镜，下一段开头要接住上一段留下的动作、视线、声音、道具或空间位置。默认不要同一人物的特写直接切同一人物的特写。
10. 局部修正：先写希望出现的正确状态，只对已经发现的高风险错误加一句局部禁止，不要堆一长串通用的负面词。

节奏提醒：非脸部的特写最多 2 秒，不要用静止的手、书页或衣袖撑一整段长台词；用表情、听者反应和少量中景、全景来承接语言和动作。
```
