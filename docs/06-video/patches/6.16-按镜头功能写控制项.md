## 6.16 按镜头功能写控制项：情绪 / 对峙 / 道具 / 动作 / 群戏 / 特写（补 6.0【四】【五】）【外部·可直接用】

**用法**：6.0 每段按“起始状态 → 触发 → 动作 → 反应 → 结果”组织，这条补的是“不同功能的镜头，各自必须写哪几项”，避免每段机械堆满所有控制项，也避免该写的漏掉（最常漏的是道具：在哪、几个、谁拿、哪只手、最后停在哪）。可以整段补进 6.0【四】后面。

**来源**：[haya-hello/AI-real-person-short-drama-workflow](https://github.com/haya-hello/AI-real-person-short-drama-workflow) docs/prompt-rules.md，MIT（收集页面，11/03）。原文照录这一部分。原仓库另外要求“对白只输出英文、每段 4~15 秒”，和我们的生产不同，没有收。

**提示词正文**：

```
不要每条镜头机械堆满所有控制项。根据镜头功能选择要写的内容。

【情绪 / 表演镜头】必须写：初始状态；触发词或触发动作；表情变化；呼吸、停顿或声音变化；禁止提前反应；结束落点。

【对峙 / 压迫镜头】必须写：前后景或左右关系；视线压力；谁压迫谁；关键词重音、停顿或尾音变化；对方的身体反应。

【道具 / 证据镜头】必须写：道具当前在哪里；是否唯一；谁拿着，哪只手接触；接触点和动作路径；道具最后停在哪里；不新增第二个、不跳位置、不换手。

【动作镜头】必须写：动作起点和终点；人物距离；手部和身体重心；环境反馈；动作结果落点。

【群戏 / 背景人群镜头】必须写：谁实焦，谁虚化；背景人群只在后景、侧边或边缘；不新增对白；不让所有人清晰露脸。背景人群没有明确动作时，一律虚化处理。

【特写锁定镜头】必须写：从头到尾保持特写；只拍哪些部位；不拍中景、全身、脚步；人物移动只能通过局部位移表现。

【通用硬约束】不让人物凭空出现、消失或跳站位；不让道具凭空出现、复制、消失、换手或跳位置；不让背景人群承担剧本没有交代的清晰动作、表情、站位或对白；道具先写当前状态，再写人物动作；每条镜头承接上一镜的站位、视线、手部和道具状态。
```
