## 6.5 画风锁定前缀块：国漫 3D 仙侠【外部·可直接用】

**用法**：做国漫 3D 修仙、玄幻类漫剧时，把下面两段原样贴在每段视频提示词的开头，全片不改，用来锁住画风和动作质感，避免集与集之间风格漂移。

**来源**：[漫剧老李 manju-laoli-skill](https://github.com/lixiaoxiao9888-create/manju-laoli-skill) short-drama-director/references/style-bible/style-prefix-blocks.md，MIT（收集页面），原文照录。同一文件里还有十几种风格块（武侠动作、神话史诗、精密悬疑、高燃动画、暗黑游戏 CG、3D 水墨等），需要时可以回原文取；原作者注明这些块都不含导演、影片等人名。

**提示词正文**：

```
【STYLE｜视觉风格 · 全片锁死】
成像底层：UE5次世代3D国漫半写实渲染，PBR物理级材质光照，皮肤次表面散射温润通透，无2D粗黑描边
形体骨相：7.5~8 头身东方仙侠修长3D建模骨相，五官立体俊朗，发丝与广袖随罡风独立物理解算飘动
影调区间：光比 [1:4, 1:8]，冷冽高空天光或秘境灵光主照明，受光面层次通透，背光侧镀清冷法术轮廓光
色彩区间：主调玄青/月白/苍蓝仙家底色配高纯度灵力撞色（幽蓝剑气/赤金符纹），饱和度 [中, 高]
空气介质：高山流云湿雾、丁达尔灵气光柱与悬浮灵力微粒（≤2 层），空间纵深通透不糊主体面部
光学区间：镜头 [18mm, 85mm]，大远景仙山牌坊巨物纵深与 85mm 浅景深眼神特写、高速环绕跟拍交替
材质响应：织金云锦暗纹、冷锻寒铁剑器高光、温润灵玉折射与崩飞青石气浪的PBR物理层次分明
特效语言：3D粒子流体三层复合法术（主体层高亮剑芒/法相本体+边缘层螺旋气浪碎石+表面层游走符文电弧）
针对性禁项：禁2D粗黑描边 / 禁日式赛璐璐平涂 / 禁廉价塑料反光 / 禁劣质网游光球糊脸 / 禁真人实拍毛孔

【PERFORMANCE｜表演与动作 · 全片锁死】
帧率区间：[24fps, 120fps]，御剑/踏空极速推拉跟拍与交击瞬间 2~3 帧顿挫定格（Hit-Stop）、慢镜衣袂回落交替
文戏眼神清冷克制、微表情细腻；打戏全程保持高密度三维空间位移与法宝实体碰撞，严禁站桩隔空对波
```
