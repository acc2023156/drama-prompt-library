## 6.4 视频提示词九段骨架 + 生成失败降级【外部·可直接用】

> **实测（11/03 第二轮）：已用于生产，并进 6.0。**

> **实测（10/30）：推荐，和 6.3 搭配使用。** 同上。

**用法**：把一个分镜段写成视频生成提示词时，按这九段的顺序填。和 6.1、6.2 的示例搭配用：示例看写法，这个看结构。后半段是「同一个镜头反复生成失败时怎么办」，做视频的同事很用得上。

**来源**：[Dramake](https://github.com/xixihhhh/ai-short-drama-skill) skills/dramake/references/prompt-compiler.md，MIT（收集页面）。摘编，原文英文字段名改成了中文。

**提示词正文**：

```
请按以下九段顺序，把这个分镜段写成视频生成提示词（按模型接受的长度压缩，但顺序不变）：

1. 场景背景：类型、时间地点、人物数量、本段的目标，以及本段唯一的剧情推进。
2. 参考素材：逐个说明每张参考图/视频负责什么（身份/服装/场景/道具/声音/动作），以及“不许从它身上带过来的东西”。
3. 空间与起始状态：人物、机位、道具、出入口的起始位置关系和尺度参照。
4. 画幅与镜头：画幅、镜头高度和焦段、主要运镜、运镜动机和终点。
5. 动作时间轴：按秒写 3~6 个节拍，每个节拍只有一个主要变化；复杂动作从已经在发生的动作开场，不要先站着等。
6. 表演与物理：谁说话、听的人什么反应、接触的过程、惯性、材质和最终稳定状态。
7. 光线与声音：有来源的光、现场声、对白来自谁、音乐的边界、段尾声音状态。
8. 必须命中：最多 1~3 个核心事件、精确的结束状态，以及和下一段的接口。
9. 负面约束：只写最可能出现、损失最大的几个错误，不要堆几十条互相打架的否定词。

不同模式的注意点：
- 文生视频：身份和空间写完整一些。
- 首帧图生视频：首帧已经决定的外观和构图不要重复描述，重点写运动、表演、声音和结束状态。
- 首尾帧：写清楚从 A 到 B 的可行运动路径，中间不要加去不了 B 的新地点或换装。
- 多参考：每个参考编号绑定职责，先删掉互相冲突的参考，参考不是越多越好。
- 视频续写：只写还没完成的动作和接下来的节拍，不复述已经发生的。

同一个镜头连续两次失败时，按这个顺序降级：
1. 保留必须命中的内容，删掉装饰动作和次要镜头；
2. 降低运镜复杂度，改成固定、好看清的机位；
3. 把“建立、高潮、后果”拆成几段分别生成；
4. 改用关键帧、动作参考或局部编辑；
5. 最后才考虑换模型或提高质量档位。
原则：一段视频只承担一个主要道具、一个高风险物理动作和一个主要回报，20~30 秒也塞不下多人轮流对白 + 复杂交接 + 变形 + 追逐 + 换地点。
```
