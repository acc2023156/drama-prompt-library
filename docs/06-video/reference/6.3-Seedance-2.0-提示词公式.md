## 6.3 Seedance 2.0 提示词公式【外部·仅参考】

> **实测（10/30）：推荐，和 6.4 搭配使用。** 选 Seedance 2.5 生成长段视频时，能让 AI 写出更细致的提示词描述。注意本条参数是 2.0 的，2.5 的官方写法见 6.9。

**用法**：自己写 Seedance 提示词时对照。

**来源**：[dexhunter/seedance2-skill](https://github.com/dexhunter/seedance2-skill/blob/main/zh/SKILL.md)，未标许可证，只作参考。

**提示词正文**：

```
公式：主体与人物 + 场景 + 动作 + 运镜 + 分时段描述 + 转场特效 + 音频设计 + 风格氛围

素材引用：用 @图片1、@视频1、@音频1 引用上传的素材，并且必须写明每个素材的用途（首帧 / 人物形象 / 运镜参考 / 节奏 / 音效）。

平台限制：单次最多 12 个文件；输出 4~15 秒；不支持写实真人脸部素材。

常见错误：引用不说明用途、指令互相冲突、一次塞进太多内容。
```
