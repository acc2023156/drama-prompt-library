## 6.11 素材锁定表与引用语法（每个素材借什么、不继承什么）【外部·可直接用】

> **实测（11/03 第二轮）：“素材锁定”的原则已用于生产**（6.0【二】：五官、发型、服装、场景外观以关联素材为准，不重复描述）。引用语法和锁定表本身不用写进提示词。

**用法**：在 X-tasy 里关联了多个画布素材时，先按这张表把每个素材的职责理清楚，再写提示词或交给 momo agent。正好对应测试反馈里「4.1、4.2 缺少关联画布素材，导致条件冲突」的问题：冲突多半是因为没说清楚一个素材该借什么、不该借什么。和 6.9（官方写法）、6.10（首镜结构）配合用，这条更细。还没实测。

**来源**：[liyue-aigc/seedance-2-5-video-director](https://github.com/liyue-aigc/seedance-2-5-video-director) references/multimodal-patterns.md，MIT（10/30 加到收集页面）。翻译摘编。作者声明为社区项目，非字节官方。

**提示词正文**：

```
写提示词之前，先把用到的每个素材整理成一张锁定表：

| 素材 | 负责什么 | 在哪段时间起作用 | 必须保留 | 不要继承 |
| @图片1 | 身份 / 场景 / 道具 / 风格 / 分镜 | 全片或某个时间段 | 要保护的特征 | 无关背景、文字、构图等 |
| @视频1 | 原片 / 动作 / 运镜 / 剪辑 / 转场 | 全片或某个时间段 | 选定的动作或画面 | 不要的人物身份、材质、声音、叠加物 |
| @音频1 | 音色 / 台词语气 / 配乐 / 节奏 / 环境声 | 全片或某个时间段 | 选定的声音特点 | 噪音、无关人声、不要的音乐 |
只填真正用到的素材，顺序和上传/关联顺序一致。

【引用语法】每次引用写成一份“小合同”：
来源素材 + 借用哪些特征 + 用在哪个主体/镜头 + 在哪段时间 + 必须保持不变的 + 不要继承的
✓ 20-25 秒仅参考 @视频2 中“预备—冲刺—起跳—挥砍”的重心和动作节奏，映射给 @图片1 的骑士；不要继承 @视频2 的灰模人物、场景材质或其他时间段的动作。
✗ 参考 @视频2 的动作。
一个素材承担多个职责时分开写；动作参考不代表也要控制人物身份、背景、声音或风格。

【人物参考图默认管什么】写“人物参考图/角色参考图”时，默认锁定整个可见角色：五官脸型、肤色、年龄感、发型发色、身材比例、可见服装鞋子配饰和整体气质；不随意改衣服、换颜色、增减配饰；看不到的背面按可见部分的款式和材质补全，不另编一套衣服。
默认不继承参考图的背景、构图、姿势、文字和光线，除非另外指定。
只想锁脸时要写明“只参考脸”，服装造型另算。
一张图里有两个人或一群人时，按位置或名字分别绑定每个人，保持相对身高；禁止换脸、互换服装、身体重复、角色互换。

【多人物】每个重要人物单独绑定：<人物A> = @图片1；<人物B> = @图片2……
逐个锁定：身份五官、发型服装、身材比例、站位或入场方向、手里的道具、动作和视线对象、有台词时的音色来源。群戏写明人数；有肢体接触时写清接触和遮挡关系，防止肢体粘连。

【音色与台词】每个声音只绑定一个角色，并写出原句：
<人物A>在 8-11 秒说“……”，音色参考 @音频1，保持低沉、克制、略带停顿的语气。
不要只写“用 @音频1”。台词长度要和时长匹配，说不完就缩短台词或拉长这一拍。

【去背景音乐】移除 @视频N 的背景音乐，仅保留清晰的人声对白和指定的现场声；画面和其他受保护的元素保持不变。

【指令冲突时按这个顺序优先】
1. 明确要保护的原片或人物身份；2. 明确的编辑对象和时间段；3. 明确的素材职责；4. 时长、台词、声音、字幕要求；5. 风格和创意补充。
同一级别的两条指令冲突时，先问清楚，不要自己选；风格参考和身份锁定冲突时，保身份，只取兼容的风格特征。
```
