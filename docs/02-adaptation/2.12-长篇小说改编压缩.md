## 2.12 长篇小说改编压缩：七种手法 + 压缩比 + 集数预算【外部·可直接用】

**用法**：一整本长篇小说要改成几十集短剧时，先用这条决定“砍什么、并什么、每卷给几集、付费卡点和大反转放在第几集”，再进入分集大纲。和 2.7（网文改编流水线）配合：2.7 讲整体流程，这条给了具体的压缩手法、压缩比算法和关键位置表。最后的“压缩决策表”可以直接让 AI 填。

**来源**：[egguy886/write-screenplay-skill](https://github.com/egguy886/write-screenplay-skill) references/long-novel-adaptation.md、templates/adaptation/02_压缩决策.md，MIT（收集页面第 31 条，11/07 继续深挖）。摘编：去掉了配套脚本的说明；原文“V.O. ≤ 对白词数 25%”是英文剧标准，这里保留为参考，中文剧按 3.11 的规程。

**提示词正文**：

```
请把下面这部长篇小说压缩改编成 ___ 集短剧（每集约 ___ 分钟），先做压缩决策，我审过之后再写分集大纲。

【一、七种压缩手法（按优先级）】
1. 保：主线因果链、每一个反转和揭示、爽点兑现、伏笔的埋设与回收。判断：删掉它，后面会不会有一处看不懂或不解气？会就保。
2. 并场：两场戏功能相同（都是“男主试探、女主圆谎”）就合成一场，取两场里最好的台词和动作。
3. 并人：功能重叠的配角合成一个（闺蜜 A + 室友 B → 一个闺蜜）。AI 出片时人越少，一致性越稳、素材越省。
4. 并景：同类场景归并成少数固定主场景（办公室、公寓、门厅、车内等），AI 短剧主场景控制在 8~12 个。
5. 三次法则：同一类桥段（圆谎、差点穿帮、吃醋）全剧最多三次：建立 → 升级 → 兑现，第四次起删或合并。
6. 浓缩：日常甜宠、时间流逝、反复的消息往来，做成 3~5 个镜头的蒙太奇，或一串手机屏幕。
7. 前移 / 重排：下一章的揭示或钩子挪到本集结尾；必要时第一集开头先闪 5 秒高潮画面再倒叙。
配套：第一人称内心戏外化为手机屏幕文字、道具特写、动作与微表情，最后才用少量旁白。
红线（不能动）：原著人物底线、尺度红线、核心卖点（例如“他早就知道”的戏剧反讽）。

【二、先算压缩比】压缩比 = 进入正剧的章节数 ÷ 目标集数
- 小于 1.2：接近一章一集，注意注水，考虑减少集数；
- 1.2~2.5：正常，每集 1~3 章，靠并场和浓缩；
- 2.5~3.5：高压缩，必须删支线、大量蒙太奇；
- 大于 3.5：超压缩，先砍整条支线和番外，否则每集都会变成剧情摘要。
番外默认不进正剧；终局打脸类番外可以并入最后一集。

【三、按“卷的作用”分配集数，不平均切】
权重：开局 1.25（前 10 集决定留存，钩子最密）、推进 1.0、中点 1.25（大掉马、大反转）、甜宠喘息 0.8（最该压缩）、危机 1.25、高潮 1.2、收尾 1.0。按“章节数 × 权重”分配。

【四、关键位置（以 60 集为例，按比例换算）】
付费卡点 第 8~12 集：一个大钩子，通常是开局卷的结尾；
第一次关系质变 第 15~22 集：让观众确信“这对能成”；
中点大反转 第 27~33 集：全剧最大的信息差爆破；
至暗时刻 第 42~50 集：分离、背叛、逃离；
高潮 第 50~57 集：最大的公开对决或追逐；
结局 第 58~60 集：兑现 + 最后的爽点，可留一个续季小钩子。

【五、请填写压缩决策表（每项写结论和理由）】
1. 支线：支线｜涉及章节｜保留 / 并入主线 / 删除 / 浓缩为蒙太奇｜理由或去向
2. 角色：原著角色｜戏份章节｜保留 / 合并 / 删除 / 只出声｜合并到谁或谁接他的戏（常驻有台词角色上限 6~8 人）
3. 场景：原著场景｜出现章节｜归并到哪个主场景（主场景清单不超过 12 个）
4. 重复桥段：桥段类型｜原著出现章节｜保留的三次（建立 / 升级 / 兑现）｜删掉的
5. 前移 / 重排：内容｜原著位置｜剧集位置｜为什么
6. 内心戏外化：原著内心信息｜外化方式（屏幕 / 道具 / 动作 / 旁白）｜首次出现集

【常见失败】每集像剧情摘要 → 压缩比过高，删支线，一集只讲一件事；集尾很平 → 按章数机械切集，按钩子点重切；看不懂动机 → 内心戏没外化；中段拖 → 甜宠卷集数给多了；钩子雷同 → 同类型钩子不连续超过 2 集。
```
