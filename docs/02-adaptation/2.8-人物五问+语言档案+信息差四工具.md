## 2.8 人物五问 + 语言档案 + 信息差四工具【外部·可直接用】

**用法**：写正文之前，先让 AI 给主要人物填好“五问”和“语言档案”，再动笔；写完每一集用最后的自检清单过一遍。专治两个问题：人物只有形容词没有选择，以及所有人说话一个腔调。“信息差四工具”用来规划秘密什么时候让观众知道、什么时候让主角知道、什么时候公开。

**来源**：[egguy886/write-screenplay-skill](https://github.com/egguy886/write-screenplay-skill) references/character-and-dialogue.md，MIT（11/02 整理人新增到收集页面）。摘编：原文以海外英文短剧为例，例子保留了思路、改成了中文场景；去掉了推荐其他仓库的说明。

**提示词正文**：

```
写剧本前，先为每个主要人物填写以下两张表，写完每一集再按自检清单检查。

【一、人物五问】
1. 他想要什么（外部、看得见）：每集的目标都是它的一小步。
2. 他需要什么（内在，自己不知道）：全剧弧光的终点，通常在全剧 70%—85% 处被逼着面对。
3. 他相信的错事是什么：驱动他一次次做错选择；解开它就是情感高潮。把它拆成 3 个试炼点（约 25% / 50% / 80%），每次都要做一次更难的选择。
4. 他身上最矛盾的一组特质：例如冷血总裁，手腕上却一直挂着她送的廉价钥匙扣。
5. 他在压力下会怎么选：列 3—5 个关键选择点（标集号），人物真相只在选择里暴露。

规则：
- 人物卡里的每个形容词，都要在剧本里找到一个代价越来越大的选择来证明。写“她很倔强”没用，要写“她卡里只剩 43 块，却一分不动那笔巨款”。
- 主角第一次出场的头 5 秒要有一个定义他的“标签动作”。好的：发完分手短信立刻拉黑、删记录、把手机扣在被子上；差的：走进宴会厅，环顾四周。
- 对手每次出手都要让主角处境更坏，并且对手觉得自己是对的。
- 配角每人一个功能（闺蜜：替主角说出心里话、撞破秘密；损友：替观众吐槽男主），功能重叠的合并。

【二、语言档案（让每个人说话不一样）】
- 句长节奏：例如总裁短句、陈述句、很少提问；反骨女主语速快、紧张时越说越长。
- 用词范围：他习惯用哪一行的词（金融、法律、游戏、农村俚语等）。
- 口头禅：不超过 3 个。
- 绝不会说的话：例如总裁不说“请”（直到道歉那一集）、不解释自己；女主不叫他的名字（直到被逼说出口那一集）。
- 说谎或心虚时的破绽：例如停顿后声音放轻、补充太多细节。
检验法：遮住说话人名字读一页对白，能认出是谁在说吗？认不出就改。

【三、对白规则】
1. 每句台词都在对另一个人做一件事（逼问、引诱、拒绝、试探）；表演提示写这个动作，不堆情绪形容词。
2. 人物很少直说真心；台词和心里话完全一样时，这句通常太直白。
3. 背景只在冲突中当武器用时才说出来（“你收了我的钱，喊了我三个月宝贝”——既是交代，也是将军）。
4. 一句话一个意思，删掉寒暄、复述、“我明白你的意思”。
5. 潜台词要能演：给演员一个可做的动作（“把杯子推回去”），比“内心挣扎”有用。
6. AI 视频限制：一句台词尽量短；避免两人抢话、同时说话。

【四、信息差四工具】
- 悬疑：观众知道得比人物少 → 好奇，用于集尾抛问题。
- 惊奇：观众和人物都不知道 → 一次性冲击，用于反转，每卷 1—2 次。
- 戏剧反讽：观众知道得比人物多 → 紧张、爽、等爆破，是言情和马甲剧的主发动机：观众先知道真相，看主角一次次差点穿帮。
- 悬念：观众知道危险将至 → 焦虑，用于倒计时、门外脚步声。
每个秘密提前排好三个时间点：观众知道 → 主角知道 → 公开；爆破点放在全剧最需要能量的位置（中点、至暗时刻）。

【五、每集自查】
- 主角本集做了至少一个有代价的选择吗？
- 每个有台词的人，说话方式和语言档案一致吗？有人说了他“绝不会说”的话吗？
- 有没有台词只在交代信息、没有在冲突里当武器？
- 本集结束时，谁知道什么，和上一集相比变了吗？
```
