## 1.12 小说 / 故事文本初筛打分（市场潜力 · 创新属性 · 内容亮点）【外部·可直接用】

**用法**：收到一批小说、故事梗概或样章，要先判断值不值得改编时用。它只根据你给的文本打分，不上网查热度和作者名气，适合匿名稿件初筛。评分从严：大多数“完整、流畅但没有明显亮点”的稿子应该落在 7.5~7.9 分，8.0 以上必须论证充分。可以配合 1.10（爽点公式）一起用：先用这条筛掉没竞争力的，再用 1.10 设计爽点。

**来源**：[VanGong1999/screen-creative-skills](https://github.com/VanGong1999/screen-creative-skills) category/novel-screening/novel-evaluator（SKILL.md 与 references/guide.md），MIT（收集页面第 60 条，11/10 深挖）。摘编：原文按“中国影视市场”写，这里改成通用的短剧口径；题材判断仍按成人线标准，红线见 7.1。

**提示词正文**：

```
请只根据我提供的故事文本做初筛打分。不检索网络，不引用文本外的热度、销量、作者名气；不编造文本里没有的情节或市场数据。

【评分维度】
一、市场潜力（从文本推断）
- 受众适合度：是否贴合这类题材的目标受众，能不能吸引他们；
- 讨论热度：能否引起共鸣，是否和当下的热点话题挂钩；
- 稀缺性：和同类故事比，有没有独特之处；
- 播放前景（推断）：这类题材改编后大概能有什么表现。
二、创新属性
- 核心选点：最核心的故事选点是否新鲜、有不可替代性；
- 故事概念：一句话能不能说清，是否突出鲜明；
- 故事设计：人物、世界观、情节、节奏、叙事等方面最突出的设计是否有独创性。
三、内容亮点
- 主题立意：是否清晰、能引起共鸣；
- 故事情境：主要情境是否有张力、让人想追下去；
- 人物设定：主要人物是否新颖、让人印象深刻；
- 人物关系：是否鲜明、有戏剧张力；
- 情节桥段：桥段是否好看，节奏是否张弛有度。

【评分标准】
- 8.5 以上：优秀，改编基础很强，可以直接跟进（从严，只有少数能到）；
- 8.0~8.4：良好，有竞争力，需要局部修改；
- 7.5~7.9：合格，中规中矩，需要较大修改；
- 7.4 以下：较差，不建议推进。
评分规则：分数细化到小数点后一位；8.0 以上必须论证充分；拿不准“良好还是合格”时判合格；没有明显亮点的，哪怕情节紧凑、故事完整，也只给合格区间——大量同类稿件都集中在 7.5~7.9。

【步骤】
1. 通读文本，形成独立理解，不引入外部设定；
2. 逐项分析打分，每项附简短依据（引用具体情节，不空泛夸赞）；
3. 给出总评、总分和跟进建议：通过 / 改后复评 / 淘汰。

【输出格式】
【市场潜力】受众适合度 / 讨论热度 / 稀缺性 / 播放前景：分析 + 评分 X.X
【创新属性】核心选点 / 故事概念 / 故事设计：分析 + 评分 X.X
【内容亮点】主题立意 / 故事情境 / 人物设定 / 人物关系 / 情节桥段：分析 + 评分 X.X
【总体评价】……总评分 X.X
【跟进建议】……
【信息边界】本评估只基于提供的文本，没有使用网络数据。
```
