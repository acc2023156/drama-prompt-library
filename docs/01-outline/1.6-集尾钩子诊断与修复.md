## 1.6 集尾钩子诊断与修复【外部·可直接用】

**用法**：某几集的结尾“不想点下一集”时，把这几集（最好连同下一集开头）和这段一起发给 AI，让它先诊断再给最小改动方案。和 1.4 的区别：1.4 是写的时候选公式，这条是写完后找问题、修问题。

**来源**：[艾玛短剧 · 编剧 Skills](https://github.com/adoria111/emma-screenwriting-skills) skills/em-episode-hooks，MIT（收集页面）。摘编。

**提示词正文**：

```
请诊断并修复以下几集的集尾钩子。先诊断，不要直接重写；我确认后再改。

【先说清观众在等什么】
用一句话写出：观众希望谁得到/摆脱什么，为什么值得在意。人物自己的目标不等于观众的愿望。
区分三件事：期待 = 想看某个结果；悬念 = 对结果、过程或代价的疑问；钩子 = 此刻追看下一步的理由。不要为了藏答案，把理解事件必需的动机、风险或规则也藏起来。

【检查钩子是怎么成立的】
还原：进入场景时的局面 → 行动/选择 → 局面变化 → 已经给到的回报 → 尚未完成的后果。只截断“准备、预约、介绍”，是没有张力的。
主导变化从这几类里选一个：即将兑现、错误认知被推翻、权力转移、关系变化、既有规则产生意外后果、不可逆的选择。
先兑现一层，再留下一层，往往比全部藏起来更有力。

【检查切在哪里】
- 集尾聚焦一个核心事件，用具体动作、证据、出场、决定或有效台词呈现；空泛狠话、没有触发的震惊不算变化。
- 不能切得太早（观众不知道在等什么），也不能太晚（只剩一个无关的新谜题）。
- 相邻几集是否在重复同一种羞辱、误会、神秘电话、“即将揭晓”或“准备去做”？换个道具但还是同一种拖延，不算推进。

【逐集输出】
现在的钩子 / 观众期待 / 用的机制 / 主要问题 / 下一集开头有没有回应（没给下一集就写“未验证”）/ 修改建议。
修复优先用最小改动：调整已有动作和信息释放的位置、收紧中断时机；不要新增人物、重大事件或世界观规则，不要提前泄露后面的秘密。默认给一个最合适的方案，确有不同取舍时最多给三个，并说明各自依据。
```
