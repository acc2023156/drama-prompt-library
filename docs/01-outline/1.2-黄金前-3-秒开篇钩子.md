## 1.2 黄金前 3 秒开篇钩子（六母型）【外部·可直接用】

**用法**：写第 1 集或每集开头前，把这段发给 AI，让它先选定一种钩子母型再动笔。也可以用来审开头：「这一集前 3 秒属于哪种母型？够不够狠？」

**来源**：[short-drama-factory](https://github.com/lixiaoxiao9888-create/short-drama-factory) references/golden-3s-hook-library.md，MIT（收集人提供）。摘编：保留六种母型和代表性变体，删去了剧名举例。

**提示词正文**：

```
写本集开头前，先从下面六种“黄金前3秒”钩子母型里选一种，并说明选择理由；开场 3 秒内必须见冲突、见危机或见反差强动作，15 秒内必须用大白话挑明具体死线或赌注。

1. 生死绝境 / 物理威胁型：开场直接把主角推向生死边缘。
   例：急救室红灯狂闪，医生推门：“病危通知书，家属签字，还差最后十分钟”；大雨中主角被按在悬崖边，反派一脚踩在他手指上。
2. 极端羞辱 / 地位反差型：反派践踏主角尊严，拉满观众的憋屈。
   注意：肢体冲突型羞辱（扇耳光、泼茶、胯下之辱）政策风险升高，优先用生活化羞辱。
   例：相亲被嫌“没房没退休金还是个瘸子”；被导师当众骂“你唱的是在侮辱音乐”；受过主角大恩的人反手把热汤泼在主角脸上骂“吃白食”（账本清算式：主角不辩解，后续逐集清算恩情账）。
3. 身份暴跌 / 狂飙暴涨型：前一秒极度卑微、后一秒顶级势力跪拜；或前一秒高高在上、下一秒被当众剥夺一切。
   例：总裁当众开除保洁，保洁摘下手套亮出集团 51% 股权印章；谈判桌上对方当众撕毁百亿合同转签宿敌；双向马甲（男女主各藏一个身份，E1 就揭破，钩子变成“知道底细后还敢不敢选”）。
4. 物证背叛 / 捉奸现场型：亲眼目睹最信任的人背叛。
   例：妻子生日推门，看见丈夫把自己母亲的传家玉镯戴在闺蜜手上；亲子鉴定显示 0.01%。
5. 反常理惊悚 / 规则悬念型：抛出违背常理的规则或现象。
   例：“这个家里，除了我，所有人都在装死”；手机收到 10 年后的短信“今晚 8 点，千万不要给你妻子开门”；视觉异变：半夜监控墙全部亮起，每块屏幕里都是同一个人站在她身后。
6. 萌系治愈反差型：极小极弱的主体 vs 极大极严肃的对象。
   例：小奶娃一个喷嚏震飞前来挑衅的神兽；2 岁萌娃一句童言让抑郁三年的老爸红了眼眶。

开篇禁令：严禁“早晨起床拉窗帘”；严禁“汽车在公路上行驶超过 2 秒”；严禁“大段旁白交代时代背景”；严禁“角色坐在咖啡厅无意义闲聊倒水”。
```
