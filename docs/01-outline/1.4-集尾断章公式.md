## 1.4 集尾断章公式（五大公式 + 五类钩子）【外部·可直接用】

**用法**：写分集大纲时，给每集指定一种断章公式；写完单集后，也可以让 AI 按这个检查结尾够不够「划不动」。

**来源**：五大公式出自 [short-drama-factory](https://github.com/lixiaoxiao9888-create/short-drama-factory) references/cliffhanger-master-formulas.md（MIT，收集人提供），摘编；五类钩子出自 [0xsline/short-drama](https://github.com/0xsline/short-drama) references/hook-design.md（MIT），其中情绪钩、信息钩、危机钩三条的例子是我按定义补写的。

**提示词正文**：

```
每集结尾必须单列一段【本集断章卡点】，格式：
【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）

从以下五大断章公式中选一种，相邻几集不要重复：
1. 身份掉马前一秒：隐藏身份即将被识破的刹那切断。
   例：反派夺过合同，看到最后一页的印章，瞳孔骤缩：“这印章……怎么会是你？！”（黑屏）
2. 物理危机绝命悬停：致命危险已爆发，伤害造成前 0.1 秒切断。
   例：货车车灯直直撞向女主，男主飞身扑出、双手刚够到她衣角的瞬间。（黑屏）
3. 反差金句霸道落地：全场嘲讽压到极致时，主角一句话震住全场。
   优先用 5~11 字生活化短句：“赵家门槛太高，我高攀不起。”“你老婆，我老公，还不止一次。”
4. 生死/利益绝境二选一：两个同样惨烈的代价，倒数读秒。
   例：“签了认罪书，你身败名裂；不签，你女儿今晚就得死在手术台上！”（黑屏）
5. 情绪反差落地（治愈系/成年人情感）：用一个克制的动作切黑，靠情感张力而不是悬念。
   例：老太太办完离婚走出民政局，门口等了她三十年的男人什么也没问，把外套披到她肩上。她低头看了一眼外套，又抬头看他。（黑屏）
漫剧专用：宝物认主/系统弹窗——主角手指悬在“是否解锁新功能”的按钮上方。（黑屏）

钩子类型参考（可与公式叠用）：
- 悬念钩：抛出关键疑问，答案留到下一集（身份/结果/选择/来者/发现）。“他缓缓摘下面具——”
- 反转钩：最后一刻颠覆预期（身份/局势/关系/时间/动机）。“头纱下面的人——不是她。”
- 情绪钩：把情绪推到最高点然后切断。
- 信息钩：透露改变全局的信息，但只说一半。“你知道你爸当年为什么……”
- 危机钩：突然出现重大危机，主角来不及反应。
设计要点：疑问必须和主线相关；下一集必须回应，可以不完全解答，但要给出新信息。
```
