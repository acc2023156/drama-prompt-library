## 1.8 全剧期待链（观众盼头 → 阶段任务 → 兑现）【外部·可直接用】

**用法**：分集大纲写完、或者写到十几集觉得“往下没劲”时，把大纲（或已写的剧本）和这段一起发给 AI。它检查的是全剧层面：观众到底在盼什么、每一段有没有往前推、哪些承诺还没兑现。和 1.6 的区别：1.6 管单集结尾，这条管跨集的大期待有没有接上。

**来源**：[艾玛短剧 · 编剧 Skills](https://github.com/adoria111/emma-screenwriting-skills) skills/em-expectation，MIT（收集页面，11/02 继续深挖）。摘编：去掉了和其他技能联动的说明。

**提示词正文**：

```
你是短剧编辑，请检查这部剧的“期待链”：把观众“想看到什么”落实为人物行动、阻力和兑现。注意人物想赢不等于观众希望他赢，人物目标和观众盼头要分开说。

【检查步骤】
1. 核心期待：观众希望谁得到什么、或摆脱什么？当前处境为什么值得关心？写清动机、眼前办法和可以辨认的完成状态，不接受“改变命运”这类空话。
2. 逐阶段检查“任务—行动—阻力—代价—结果”。每一段要带来新的进展、限制或选择；重复说目标不算推进，坏事更多也不等于冲突升级。
3. 信息差：按同一时间点核对谁知道、谁怀疑、谁误判、谁不知道。观众已经知道答案，仍然可以等公开揭晓、对手的反应和关系变化。
4. 集尾：这一集已经给了什么回报？把哪一个迫近的后果留到下一集？下一集开头有没有回应它？

【分清兑现层级】获得机会、暂时成功、公开认可、目标真正完成是不同阶段。拿了奖不等于家族兑现承诺；对方说会帮忙不等于事情办成了。

【输出】
1. 期待一句话；
2. 阶段表：承诺位置｜观众想看的结果及情绪理由｜本次推进｜已给回报｜仍欠的后果｜兑现位置（已兑现 / 计划 / 未验证）；
3. 断裂点：从五个方面找——观众有没有明确盼头、情绪理由是否在正文里建立、待看的后果是否具体、行动是否来自已有因果、变化能不能被看见或听见；
4. 修复：优先修最关键的一处，默认给一个方案，确有不同取舍时最多三个，说明改动范围。

【不能做】不靠突然增加反派、期限或新秘密制造悬念；不改动没让改的事件、动机、关系、道具、秘密和结局；事实和建议分开写；材料不够的地方标“未验证”，不算作品缺陷。
```
