## B. 只做了摘要的参考资料

这些资料有价值，但要么太长、要么是给 Agent 工具用的、要么许可受限，没有整理成提示词正文：

- [zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills)（MIT，3.2k star）：十个技能覆盖原著快评、分集地图、剧本、资产、分镜、视频提示词、审查。11/03 已摘 6.13、6.14；剧本部分（script-craft、台词）下一批摘。
- [漫剧老李整套](https://github.com/lixiaoxiao9888-create/manju-laoli-skill)（MIT）：一个总控加 12 个子技能，内容量最大（140 多份文档）。已摘称呼系统、五席圆桌审核、仙侠画风块；下一批候选：其余画风前缀块、角色定妆模板、方言声线词典、打戏节奏规则。
- [Open Film Skills](https://github.com/62656456/ai-film-skills)（Apache-2.0，明确允许商用）：21 个影视技能，含爱情、武侠、恐怖、悬疑等 8 种类型的视觉设计预设，都是给 Agent 工具用的规则，需要时可以参考。
- [Dramake](https://github.com/xixihhhh/ai-short-drama-skill)（MIT）：除 6.4 外，还有身份/声线锁定、连续性与转场、喜剧与动画表演等参考文件。
- [short-drama-factory](https://github.com/lixiaoxiao9888-create/short-drama-factory) 其余部分（MIT）：人物圣经、冲突形态五型、剧本医生问题卡、40 赛道题材图、跨集连续性台账，下一批可摘。
- [艾玛短剧 · 编剧 Skills](https://github.com/adoria111/emma-screenwriting-skills) 其余部分（MIT）：22 个短剧技能，已收录 6 个（1.6、1.8、3.8、3.9、3.12、3.15）；还剩集纲扩写成正文、对标改编、选题迭代，以及一整组海外短剧（选题、英文本地化、过稿检查、投稿包）。
- [山音超级编剧大师](https://github.com/Shanyin-ai/shanyin-screenwriting-master) 整份（MIT，保留署名）：约 13 万字，可以整份拖进 AI 对话框使用，偏电影和剧集，含概念短片的创意方法、双轨节奏、时长估算。
- [short-drama-prompt-director](https://github.com/zouchenzhen/short-drama-prompt-director) 其余部分（MIT）：导演规则、镜头参数规则、续写与重拍的状态管理。
- [Hao0321/ai-short-drama](https://github.com/Hao0321/ai-short-drama)（MIT）：「假废物真强者、重生、系统、隐藏大佬、逆袭」类题材的 AI 短剧系统（繁体中文），给 Agent 工具用，含题材引擎和概念八维评分，可以参考。
- [jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills)（MIT）：作者从 47 本编剧理论书和 23 卷出版剧本提炼出的 26 个技能，偏传统影视编剧理论。内容来自他人出版物，只作学习参考，不收录正文。
- [awesome-short-drama-skills](https://github.com/liangzemian/awesome-short-drama-skills)（CC0）：83 个短剧 skill 精选清单，按“写剧本 / 定选题 / 分镜 / 视频模型”分类。它的[第一轮实测](https://shortdramaskills.com/evals/round-1/)里，三次都赢过“不装 skill”对照组的 5 个剧本 skill 是 zenstory、山音、jtydhr88、Hao0321、艾玛短剧，除 zenstory 外我们都已收录或摘要过；实测也指出集尾钩子反而常是对照组更强，且只测了一个模型。后续可按它的分类继续找。
- [LuxReal short-drama-skills](https://github.com/YvonneMovingon/short-drama-skills)（MIT）：7 份可直接粘贴的提示词文件（叙事拆解成镜头、深度情绪刻画、详细动态描述、按剧情拆分、单视频提示词润色、高能/慢节奏两种润色），作者称经过大量创作者生产验证，支持带资产标签输入。偏“文字写镜头”，按测试结论不收正文；如果想对比 momo agent 的分镜效果，可以拿 01 叙事拆解测一次。
- [UncleWang2088/short-drama-director](https://github.com/UncleWang2088/short-drama-director)（未标许可证）：短剧导演专家包，剧本创作、平台标准审稿、真实演技对话、Seedance 2.5 提示词、LIBTV 画布同步。只作参考。
- [ye4wzp/seedance2.5-prompt-skill](https://github.com/ye4wzp/seedance2.5-prompt-skill)（MIT）：MapleShaw 2.0 版技能的 2.5 改版，增加 30 秒单条直出决策树；内容和 6.9 官方写法大量重合。
- [XiaoLuo-AI-Drama-Skill](https://github.com/zhurui0523/XiaoLuo-AI-Drama-Skill)（未标许可证，487 star）：20 份中文提示词文件，覆盖剧本分析、原创改编、分镜、角色三视图/服装/表情、场景布局。只作参考。

## D. 收集人提供文件的评估

**short-drama-factory（SKILL.md + GitHub 仓库）**：本批质量最高的来源。作者和「漫剧老李」是同一人，MIT 许可，专门针对抖音/红果短剧，规则很细（台词七维、15 秒换挡、强画面、合规红线），还附带自动检查脚本。上传的 SKILL.md 和仓库里的是同一个文件，它本身是给 Agent 工具用的总目录，真正的内容在仓库的 references 文件夹里，本文 1.2、1.3、1.4、2.4、3.3、7.1 都是从那里摘编的。

**script_writer_prompt.md**：部分有用。它是一套英文的「小说转视频」流程，强项是角色参考表、连续性状态表和四格分镜板（已节选翻译为 4.2、5.1、5.2、5.3）。不适合整份直接用，原因有四：
1. 它按 20 秒横屏场景设计，不是竖屏短剧的节奏，也没有钩子、卡点、爽点这些短剧要素；
2. 输出格式非常重（每场都有一大段 XML），用在聊天框里会很长；
3. 里面写死了作者个人电脑的路径和本地生图模型（Z-Image Turbo / Amuse），而且明显偏科幻题材；
4. 出处只标了「Robert's Tech Toolbox」，没有许可证。

10/28 补充：这份文件来自 GitHub 仓库 [Roland7869/book-to-screen](https://github.com/Roland7869/book-to-screen)。仓库里还有一份 character_sheet_prompt.md（角色设定表生成），但它是给作者自己的 Python 程序配套用的，依赖 Obsidian 笔记库，没有收录。
