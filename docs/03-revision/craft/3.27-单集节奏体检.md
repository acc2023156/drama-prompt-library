## 3.27 单集节奏体检：一集一个变化 + 按掉点位置找病因【外部·可直接用】

**用法**：单集写完后做节奏体检，或者拿到后台留存数据后反推哪里出了问题。先确认这一集交付了一个明确的“从 A 变成 B”，填不出来的集要合并或删掉；再按观众划走的位置对照病因表找最小修法。和 1.9（弱开场五种失效）、3.22（剧本评审与修复）配合用。

**来源**：[liuxiao20051106-prog/ai-manga-drama](https://github.com/liuxiao20051106-prog/ai-manga-drama) references/craft-short-form-narrative.md，MIT。摘编。

**提示词正文**：

```
请给这一集剧本做节奏体检。

【一、这一集交付的“变化”】
写出一句：本集什么从 A 变成了 B？（关系 / 处境 / 认知 / 情绪，四选一或多选）
填不出来的，建议与相邻集合并，或删掉。

【二、按区间检查（参考节奏，不要机械套秒数）】
| 区间 | 观众在问 | 必须给的 |
| 0–3 秒 | 值得停吗？ | 冲突、异常或强情绪画面；不放世界观和人物介绍 |
| 3–15 秒 | 发生了什么？ | 一次交代清：谁、要什么、被什么挡住 |
| 中段 | 接下来呢？ | 每 5–10 秒一个信息增量或小转折 |
| 最后 20% | 结果是什么？ | 兑现本集回报（那个 A→B） |
| 结尾 | 然后呢？ | 钩子：悬念 / 反转 / 情绪停在最尖处 / 停在选择的那一刻 |
钩子必须由剧情自然产生；故意藏起观众已经看见的信息，会被当成剪辑错误。

【三、掉点诊断】
| 掉点位置 | 大概率病因 | 最小修法 |
| 前 3 秒 | 开头是风景、介绍、标题 | 换成冲突画面或异常状态 |
| 3–15 秒 | 人物和目标没交代清 | 用一句台词说完“谁、要什么、被什么挡住” |
| 中段 | 连续平淡，没有新信息 | 插一个小转折或新信息，或整段压缩 |
| 70% 处 | 观众已经猜到结果 | 提前给掉回报，把结尾留给新问题 |
| 结尾 | 钩子太软或收得太干净 | 换钩子类型；最后一个镜头停在“未完成” |

【四、常见失败】
流水账（只有“然后”没有“因此”）→ 补因果；
平淡（人物太顺）→ 加时间压力、代价或对手；
太赶（一集塞两集内容）→ 拆集，不压缩情绪。

【输出】
本集的 A→B；逐区间的“有 / 没有 / 问题”；需要改的地方按“位置 → 病因 → 改法”列出。
```
