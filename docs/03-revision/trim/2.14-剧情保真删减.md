## 2.14 剧情保真删减：只删纯冗余，节奏靠表达密度不靠砍节点【外部·可直接用】

**用法**：小说改剧本、压缩剧本时用，专门防止“为了节奏快把剧情删没了”。核心是分清“精简表达”和“删减内容”：要快就写短句、切得密、台词精炼，剧情节点一个都不能消失。压完后逐段对照原文自检。和 2.12（长篇小说改编压缩）、3.9（剧本删减）配合用：2.12 定压缩比和集数预算，这条管“删什么、不能删什么”。

**来源**：[senmanx/novel-to-manju](https://github.com/senmanx/novel-to-manju) SKILL.md 第 2.5 节“剧情保真原则”、第 3.1 和 4.1 节的精简规则，CC0（公共领域，可自由使用）。摘编。

**提示词正文**：

```
请按“剧情保真”原则压缩下面的原文（或剧本）。剧情保真优先级最高，高于所有“精简 / 删减 / 节奏快”的要求。

【一、不能删的】
推动主线的情节、关键转折、人物成长、重要伏笔、世界观设定，一律完整保留；不得以“节奏快”为由跳过或合并。
与主线人物、结局、伏笔有关的支线必须保留；只有完全独立、与主线零交集的支线，先标出来，由我决定去留。
拿不准能不能删的，一律保留。

【二、可以删的（纯冗余）】
只有同时满足以下四条的内容才能删：不影响剧情理解、不塑造人物、不铺垫后续、不渲染氛围。
典型的纯冗余：凑字数的重复描写、无意义的修辞、同一心理活动的反复描写、大段环境堆砌。

【三、要快，靠表达密度】
精简的是表达方式，不是内容：
- 冗长修饰改成短句，重复心理描写改成一个动作或一句台词；
- 一个剧情节点可以用两个快切镜头讲完，但不能直接消失；
- 背景信息用对话、动作、内心独白穿插交代，不直接砍掉；
- 一集装不下就拆成两集，不靠删剧情凑时长。

【四、压完自检】
逐段对照原文，确认每个事件、每次对话、每个伏笔都还在；
若某段被压缩，标明它的信息并进了哪一段，而不是丢了；
最后列出：①删掉了哪些内容（应全部属于纯冗余）；②被标出待我决定的独立支线。
```
