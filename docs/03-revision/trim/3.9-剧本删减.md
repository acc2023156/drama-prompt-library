## 3.9 剧本删减：A—B—C 试删法【外部·可直接用】

> **实测（11/03 第二轮）：已用于生产。** 和 3.11、3.12 一起被并进了视频专用提示词（6.0）。

**用法**：单集字数超了、节奏拖沓时用。1.0 的 3.2 里有一条「删减台词、动作、环境描写」的指令，这条把「怎么删才不伤剧情」讲清楚了，可以替换或配合那条用。

**来源**：[艾玛短剧 · 编剧 Skills](https://github.com/adoria111/emma-screenwriting-skills) skills/em-script-trim，MIT（收集页面）。摘编。

**提示词正文**：

```
请删减这一集剧本中的无效过场、重复信息和冗余表达，保留必要的因果、情绪和表演过程。先看整段，再看句子，最后删词。

【A—B—C 试删】
A 是保留的前段，B 是准备删的段，C 是保留的后段。标清 B 的起止，然后把 A 直接接 C 连读，检查：
- 回应还有没有对象？人物的位置和手里的东西还接不接得上？
- B 是否带来了别处没有的信息、选择或情绪回报？
如果 B 的作用已经被别处承担，指出是哪一句或哪个动作承担的。观众知道不等于人物知道；剧情接得上，也不等于情绪没有损失（要说明会少掉什么笑点、释放或必要的停顿）。

【怎么删】
1. 先找：重复到达、完整重演、没有新结果的争吵、反复解释、进入关键事件前的冗长手续。
2. 整段确实多余就删整段，不要只删几个词却留着多余的一轮戏。如果删了必须新补一句解释才接得上，标出来作为“需要修复的候选”。
3. 删完查依赖：删了举拳，后面就不能还写“握住拳头”；删一句话，要检查针对它的反驳；删了道具的来源，后面的道具不能凭空出现。
4. 所有删改同时生效后再连读一遍。

【边界】
- 同一个秘密分别告诉两个不知情的人，不算重复；同一句质问从试探变成宣判，可能是关系在推进。
- “有气氛”不是自动保留的理由，“没有新事实”也不是自动删除的理由，要落到具体后果上判断。
- 不设固定删字比例；保持角色的说话方式和结尾不变。

【输出】
先给建议：每处删除的确切范围、A→C 怎么接、理由和取舍；我确认后再给完整修订稿和简要变更说明，注明删减前后的字数。
```
