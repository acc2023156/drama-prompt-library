## 3.26 台词字数预算 + “塞不下”怎么改 + 能不露嘴就不露嘴【外部·可直接用】

**用法**：写对白、压对白、给分镜表定时长时用。先按语速算出这一集（这一段）能放多少字，超了就砍台词，不加快语速。第三部分是口型的取舍：先问这一镜能不能不露嘴（侧脸、背身、切走、改成 OS/VO），能就不做口型。和 3.11（独白与旁白规程）、3.24（台词引擎）、6.13（对白时长预算）配合用。

**来源**：[liuxiao20051106-prog/ai-manga-drama](https://github.com/liuxiao20051106-prog/ai-manga-drama) references/craft-dialogue-voice-and-sound.md 和 craft-short-form-narrative.md，MIT。摘编；原文面向漫剧，口型部分按真人短剧的情况做了提醒。

**提示词正文**：

```
请按以下规则检查并修改这一集的对白和旁白。

【一、先算字数预算】
中文配音常见语速约 4–5 字/秒（情绪激动可以稍快）。
30 秒 ≈ 90–130 字，60 秒 ≈ 180–250 字（含旁白和 OS）。
先算出这一集（或每一段）的有效台词字数上限，再开始写。
交给画面的信息越多，留给台词的字数就越少：能用一个动作、一个道具、一个表情说清的，不写进台词。

【二、超了怎么改】
- 砍台词，不要加快语速（语速一快，情绪就没了）；
- 一句只放一个信息：“因为三年前那件事，所以我一直不敢回来”拆成两句，中间给一个画面；
- 不写解释性台词：人物不解释自己为什么这么做，让画面和后果说明；
- 每句要念得顺，念不顺就改，不靠配音硬扛；
- 每 2–3 句之间留半拍到一拍的空隙，给音效和情绪留位置。

【三、口型怎么取舍（先问能不能不露嘴）】
1. 不露嘴：侧脸、背身、镜头切到听者或道具，或者把这句改成 OS / VO —— 代价最低，也不露破绽；
2. 正脸说话的中近景，靠模型自带的口型能力；
3. 必须看嘴的特写，才考虑用专门的口型工具。
OS / VO 一律不做口型，也不要让画面里的人物张嘴。
提醒：真人短剧观众对口型比漫剧更敏感，关键对白镜头不要全部用不露嘴的方式回避。

【四、常见问题】
| 症状 | 原因 | 改法 |
| 台词塞不下 | 超过字数预算 | 砍台词，不加速 |
| 听着假 | 每句都是完整书面句 | 改口语，加停顿、语气词 |
| 口型对不上 | 时长估错，或这一句本不必露嘴 | 先按字数定时长；或改成 OS/VO、切到听者 |

【输出】
先给出预算（总时长、字数上限、现有字数），再逐句列出：原句 → 改后 → 改法（砍 / 拆 / 改口语 / 改 OS/VO / 切到听者）。
```
