## 3.4 台词称呼系统【外部·可直接用】

**用法**：润色台词时用，让人物之间的称呼随关系和场合变化，台词更像人说的。

**来源**：[漫剧老李 manju-laoli-skill](https://github.com/lixiaoxiao9888-create/manju-laoli-skill) sd-script-engine/references/dialogue-naturalization.md，MIT（1.1k star，和 short-drama-factory 是同一作者）。原文约 2.7 万字，这里只摘编了「称呼系统」一节。

**提示词正文**：

```
请检查并改写剧本中的称呼，让台词更口语、更像人说的。规则：

一、称呼由四个变量决定：身份（尊/平/卑、年龄差）× 关系（生疏/熟识/亲密/决裂/旧情/上下级）× 场合（公开/私密）× 情绪（平静/动情/恼火/示弱/挑衅）。任一变化，称呼就该变。

二、同一对象的七种叫法（现代 / 古装）：
- 公开·正式：“陈总监” / “陈大人”
- 私下·熟识：“老陈” / “陈兄”
- 亲密·动情：“阿默” / “默郎”
- 示弱·求人：“陈总，您看……” / “大人，小人斗胆……”
- 恼火·决裂：连名带姓“陈默！”
- 挑衅·敌意：反讽敬称“陈大总监” / “陈大人好大的官威”
- 划清界线：从“老陈”退回“陈总监”
称呼的“降格”和“退回”比“升格”更有戏。

三、三条铁律：
1. 同一角色对同一对象，在同一关系阶段的称呼必须稳定，跨集不得漂移；要变，必须有事件触发。
2. 称呼只反映关系，不替代事件：关系要靠经历、试探、保护、背叛推进，不能只改称呼。
3. 不同角色对同一对象的称呼要有区分（一个叫“爸”，一个叫“老李”，一个叫“李队”）。

总则：口语化不等于加废话，也不等于拉低身份——粗人糙话、书生引典、杀手惜字。

输出：先列一张称呼表（谁对谁、当前关系、用什么称呼），再给改写后的台词。
```
