## 3.24 台词引擎：一句一功能 + 四种台词技巧 + 压缩时保住爆发句【外部·可直接用】

**用法**：写对白、改对白时用，尤其是 AI 仿真人剧这类“台词不宜多、一句要顶一句”的项目。四种技巧（对比、曲解、PUA 式“为你好”、金句）是写反派话术和高潮台词最常用的手法。第五部分是压稿时容易犯的错：把有铺垫的爆发台词和关系宣判句当成“重复”删掉。和 3.15（台词效率逐句评分）、3.21（台词是一种行动）配合用。

**来源**：主体出自 [艾玛短剧 · 编剧 Skills](https://github.com/adoria111/emma-screenwriting-skills) advanced/story-writing/skills/em-chief-writer/references/writing-rules.md “台词引擎”一节，MIT（11/11）；第五部分出自 [zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills) script-craft.md 的 SCR-23（11/01 新增，作者做过一组压稿对照：加这条之前，有铺垫的爆发和宣判句 3 次里 2 次被删，加之后 0 次被删、空喊仍照删），MIT。摘编。

**提示词正文**：

```
请按以下规则写（或改）这场戏的对白。

【一、一句台词一个功能】
每句都提供新信息或推进情绪，不在同一层面来回说同一件事；每句都要回应上一句，并有新进展。单条台词太长（超过三行左右）就精简或加气口。
一句台词可以承担的功能（同一段对话里轮换，不重复）：警告、反驳、亮明目的、道出背景、犀利拒绝、威胁升级、羞辱、嘲讽、揭示信息、下达态度。
一字之差，人设天壤（先想清楚此刻谁强谁弱）：“你果然背弃了誓言”——说话的人是掌控者；“你竟然背叛了我们曾经的誓言”——说话的人是受害者。

【二、信息去重】
- 同一集内：同一个事实只说一次（“你们不关心我”“要八十万”说一次就够）。
- 可以跨集重复、用来持续刺激的只有两类：反派做过的核心恶事（不同集、不同人、不同情境下提起）；人物的核心标签（“她是扫把星”“他是窝囊废”，多次强化，为打脸铺垫）。
- 信息叠加是递进不是并列：骂人 → 推搡 → 毁坏重要物品 → 牵连亲人。

【三、四种台词技巧】
1. 对比法（抬高一方、贬低另一方）：“你连 ___ 的一根头发都比不上”“虽然你 ___，但 ___ 才是 ___”。例：父母把钱分给哥哥和妹妹，唯独不给主角，还说是为他好。
2. 故意曲解 / 扣帽子：把对方的正当诉求恶意歪曲。例：女主说“我想离婚”→“你就是想跟那个野男人跑吧？”；女主说要去工作 →“你就是想勾引老板。”
3. “我都是为你好”：施害者站在道德制高点，让受害者有苦说不出，最能激起观众愤怒。例：“你弟弟是咱家的命根子，你不帮他谁帮他？我们养你这么大容易吗？”
4. 金句法（用在高潮、觉醒、反转时）：对仗俗语（“靠山山会倒，靠人人会跑”）、具象比喻、价值观反转（“爱不是束缚，应该是托举”）、递进排比。
反派话术按功能取用：当众捧高踩低；把正当行为曲解成出轨或被收买；以退为进扮无辜；用“恩情 + 牺牲”道德绑架；把努力污名化成“出风头”；用“办正事”装公正掩盖偏心。
OS / VO：用一句内心独白替观众点破潜台词，同时完成“揭示信息 + 扎心”；只点出当前可知的隐情，不替观众解释每个动作（详见 3.11）。

【四、压缩流程】
1. 标出每句的功能；
2. 找出功能重复的句子，只保留一次；
3. 把分散的背景信息融合进一句；
4. 确认每句都有新进展，连成链条：警告 → 反驳 → 目的 → 背景 + 拒绝 → 动作 → 威胁升级；
5. 长段心理描写改成简短有力的动作或对话。
吵架要回合制层层升级，有来有回、句句戳心，不是一个回合重复对骂。

【五、压稿时保住这场戏的回报】
压稿前先认出这场戏的峰值。峰值上三样东西都承重：前面压力铺垫出来的爆发台词、紧跟其后的关系宣判句（例如“我们之间，到此为止。”）、收住这一拍的动作（例如离场）。即使离场已经表明了决定，宣判句也不算重复。
时长不够时先删别处：过场、重复验证、解释，必要时整场合并；爆发台词只压缩其中重复的部分，保留铺垫指向的那一句。
没有铺垫、不带来新情绪阶段、和前文同义的空喊照删。

【自检】每句都有独立功能；同一集内同一事实没被反复说；跨集重复的只有核心罪证和人物标签，且每次有新情境；强弱定位正确；长心理描写已改成动作或对话；峰值上的爆发句和宣判句还在。
```
