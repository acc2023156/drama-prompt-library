## 3.3 台词七维诊断（大白话直给 + 快慢变速）【外部·可直接用】

**用法**：剧本初稿写完后，把这段和剧本一起发给 AI 做台词精修。它专治 AI 台词的几种老毛病：播音腔、对着对手念背景、只亮物证不说结论（观众看不懂）、满嘴术语、每句一样长。可以补 1.0「台词长度不再机械卡死」那条没展开的部分。

**来源**：[short-drama-factory](https://github.com/lixiaoxiao9888-create/short-drama-factory) references/dialogue-doctor-anti-ai.md，MIT（收集人提供）。摘编：保留七个维度和改写示例，去掉了机检编号；原文用「△」标动作，这里改成「▲」。

**提示词正文**：

```
请按以下“台词七维”逐条诊断并改写剧本台词。先列出每一维发现的问题（标出第几场、哪一句），再给出改写后的完整剧本。

维度 1：角色语言指纹——遮住人名，能否一眼看出是谁在说话？
- 恶霸/市井反派：短促施压词、命令句、市井俚语（“听懂没有”“少废话”）；
- 隐忍/上位主角：字数精炼、情绪克制，用反问和具体代价制造威慑（“你确定？”“这笔账，现在算”）；
- 质疑者/捧哏配角：替观众把疑问、憋屈或震惊直接喊出来（“他疯了吧？”）；
- 谋士/助理/管家：恭敬短句，带具体数字和时间死线（“三分钟内办妥”）。
严禁全员文绉绉、全员播音腔。

维度 2：禁止反向灌输——不许角色对着对手念双方都知道的背景。
✗ “三年前你害死了我爸，侵占了我们林家三千万财产，今天我一定要让你血债血偿！”
✓ ▲林辰将染血的旧怀表重重拍在桌上，表盖弹开。
  林辰（冷声）：三年前林家老宅那场火，烧得挺旺啊，赵董。
  林辰：你吞下去的三千万，今天连本带利吐出来！

维度 3：攻防回合制——每轮对话必须形成“施压 → 反刺探/亮牌 → 恼羞加码 → 绝杀算账”。
反派：十万块，签了这份谅解书。
主角：十万？你儿子的前途，就值这点？
反派：你别给脸不要脸！
主角：明早九点前不凑齐五百万，咱们法庭见。

维度 4：单句气口——常规句 12~18 字；快刀句 3~6 字；爆发金句 8~12 字；单气口上限 25 字，一行含两层意思就拆成两行。

维度 5：物证 + 大白话结论同轮直给——潜台词靠神态和动作演，但事实和利害结论必须在 1~2 句内用大白话挑明，不许打哑谜。
✗ ▲她摸了摸碗边。 女主：这碗边没水印。你还是老样子。（观众看不懂）
✓ ▲她一把将粗瓷碗翻过来，手指在碗底抹出一层干面粉！
  女主（眼圈发红｜急促）：刚洗过的碗，碗底哪来的干面粉？
  女主：你早上根本没吃饭，把最后两个馍全留给我了！

维度 6：术语和设定词当句翻译——专业术语、古语、玄学词出现时，当句或下一句必须翻译成后果（多少钱、判几年、谁死谁活）。
✗ “林总，对方启动了交叉违约触发机制，我们的流动性敞口已经彻底暴露了！”
✓ “林总，银行刚刚抽贷了！今晚十二点前凑不出三千万现金，明早公司大楼直接被查封拍卖！”

维度 7：快慢变速——先用 3~6 字快刀句劈开局面，再跟 8~16 字算账句亮筹码，不许每句都一样长。
✗ 甲：你今天如果不把这份合同签了，我就让你在江城混不下去。
✓ 甲（拍桌｜厉声）：签了它！不签，明天让你滚出江城！
  乙（掀起眼皮｜冷笑）：滚出江城？
  乙（甩出股权书｜一字一顿）：睁大眼看看，这栋楼现在的房东是谁！

附加要求：每 2~4 句对白穿插一条拍得出来的 ▲ 强视觉动作，连续纯对白不超过 6 行。
```
