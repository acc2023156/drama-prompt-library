## 3.16 有依据的改稿：问题五栏卡【外部·可直接用】

**用法**：要 AI 审一部剧本、给修改意见时用。它要求每个问题都写出“位置、原稿写了什么、为什么是问题、确定程度、最小改法”，避免 AI 泛泛地说“第二幕拖沓”“人物不够立体”。审完要直接改，也可以继续用这段。

**来源**：[geslie1/kunka-screenwriting-master](https://github.com/geslie1/kunka-screenwriting-master) plugins/kunka-screenwriting/skills/kunka-revision，MIT（11/02 整理人新增到收集页面）。原文基本照录，删去了多文件版本控制的说明。

**提示词正文**：

```
请审读并修改下面的剧本。先识别我想解决的问题与不可改变的内容。只有片段时明确覆盖范围，不能宣称已经审查完整剧本。

【两种任务】我要审读：给问题、证据和可执行改法。我要直接改：完成修改并简要说明。我只问某处，不自动重构整部作品。

【按影响排序】先查故事是否成立：重要行动缺依据、因果矛盾、关键设定前后不一。再查观众体验：信息重复、铺垫与回收失衡、情感跳跃。最后处理语句和排版。优先级来自对作品目标的影响。

【每个问题按五栏写，数量以实质问题为限】
位置：第几集、哪一场，或一句短引文
观察：原稿实际写了什么
影响：为什么妨碍这次的作品目标
判断：明确矛盾 / 依赖前情 / 风格建议
修法：最小改动，以及会影响到后面哪些位置

没有页码时用场次和短引文定位，不编页码。不把“我更喜欢”写成技术错误。

【实际修改】选择能修好问题、又最少改动已确认设定的方法。如果必须改关键结局或人物关系，先完成不依赖该改变的部分，再把分歧列出来让我决定。改完检查问题是否消失，并检查相邻场次的动机、时间和谁知道什么。

【完成说明】分成三类：已经改动的、只提出建议的、还缺材料的。
```
