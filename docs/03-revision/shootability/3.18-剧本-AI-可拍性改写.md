## 3.18 剧本 AI 可拍性改写：难生成的戏怎么改【外部·可直接用】

**用法**：剧本定稿后、做分镜表之前，把剧本和这段一起发给 AI，让它标出 AI 视频难生成的场面，并给出不改剧情的改写方案（内心戏改成可见动作、打斗改成特写加音效、大场面改成局部等）。对应专用提示词（6.0）【一】第 4 条“难以生成的镜头可以调整”——在剧本阶段先改好，分镜阶段就少返工。

**来源**：[YubAI-DramaFlow](https://github.com/xiaoqinyudan2022-hue/YubAI-DramaFlow) references/剧本AI适配原则.md + templates/AI可行性评估模板.md，MIT（收集页面，11/03）。摘编：去掉了 emoji、评分签名表和案例。**注意**：原文的“擅长/困难/几乎不可能”是作者 2024 年按当时工具总结的，我们现在用 Seedance 2.5 + 画布素材，双人戏、人物一致性已经不是大问题，下面的难度分级请按实际出片情况调整；有价值的是后半部分的改写方法。

**提示词正文**：

```
请检查下面的剧本在 AI 视频生成上的可拍性，标出高风险场面，并给出不改变剧情结果的改写方案。

【一、风险分级（按我们实际使用的模型调整）】
- 低风险：固定或缓慢运镜；单人近景、特写；转身、抬手、行走、坐下等简单动作；室内柔光、暖光、黄昏。
- 中风险：吃东西、拥抱、奔跑；雨雪夜景；精细道具（书页、茶杯）；三人以上同框。
- 高风险：打斗、舞蹈等复杂肢体动作；写字、弹琴等精细手部动作；需要看清的文字内容；爆炸、法术等大特效；千军万马等大场面；强闪光、极暗环境。

【二、改写方法（只改呈现方式，不改事件结果）】
内心戏：
- 心想“我一定要成功” → 眼神坚定，握紧拳头；
- 内心纠结 → 低头沉默，手指无意识地绞着衣角；
- 回忆过去 → 叠化转场 + 旁白。
动作戏：
- 激烈打斗 → 拔剑特写 + 音效 + 关键一击的结果镜头；
- 奔跑追逐 → 回头特写 + 脚步声；
- 舞蹈 → 舞姿定格 + 音乐。
特效戏：
- 法术攻击 → 手部特写 + 光效 + 音效；
- 爆炸 → 火光闪烁 + 音效 + 远景；
- 暴风雨 → 人物在雨中 + 雨声 + 闪电光。
大场面：
- 宫殿金碧辉煌、宫女成群 → 镜头 1 主角端坐特写；镜头 2 宫女剪影；
- 战场刀光剑影 → 镜头 1 主将拔剑特写；镜头 2 战场远景虚化。

【三、场景与人物控制】
- 相近场景合并（同一地点不拆多场），能复用的场景复用，室内优先。
- 主要角色 2~3 人详细设计，次要角色 1~2 人可用侧影、背影，群演省略或虚化。
- 主角单人镜头尽量占多数。

【输出】
1. 高风险场面表：位置（第几集第几场）｜原文｜风险类型｜改写方案；
2. 改写后检查：情节是否完整、情感表达是否还在、叙事是否流畅。
```
