## 3.1 Seedance 2.0 剧本改编准则【内部 1.0】

**用法**：见上方 1.0 原用法。

**提示词正文**：

```
Seedance 2.0 剧本改编准则（执行版）

一、 结构与排版
单行原则： 场景行、人物行、动作行（以 ▲ 开头）、台词行、转场行必须严格独立成行，绝不混排。
动作明确： 动作行需由“主语+动作+对象”组成（如：▲陆骁反手握住苏清影），严禁用形容词代替行为。

二、 台词规范
字数限制： 单句台词（含标点）严禁超过 25 字。
拆分原则： 超过 25 字必须拆分，拆分后单句不得超过 15 字，确保语音断句自然、AI 表情不僵硬。

三、 括号标注规范（关键）
内容逻辑： 括号 () 内必须是 “动作 + 情绪” 或 “单一动词/形容词”。拒绝废话描述，必须是指导角色“怎么演”。
换行重标： 只要台词换行，无论是否同一人，每一行都必须重新标注，不得省略。
情绪递进： 同一场戏内，标注词严禁重复，应根据角色心理变化体现层级（如：由“冷笑”递进至“咆哮”或“森寒”）。
禁止堆叠： 标注文字限制在 1-2 个词，拒绝长句子。

四、 视觉生成准则（适配AI）
具象行为优先： 尽量写入涉及道具、位置、肢体交互的动作指令（如：指着鼻子、猛地拍桌、贴耳低语），以触发 Seedance 2.0 的高水准画面重构。
镜头语言： 动作行中可适当穿插简单的镜头指令（如：镜头推进、特写、俯拍），引导画面重心。

【准则自检范例】
错误写法：
陆骁（语气非常严厉，而且很生气）：现在的政策变了，我们这是正当买卖，根本不是什么投机倒把。

正确写法（适配版）：
陆骁（一字一顿，冷峻）：现在的政策早就变了。
陆骁（挥手，严肃）：这是正当买卖。
陆骁（冷哼）：根本不是什么投机倒把。
```
