## 3.25 导演剧本微调：先修“不可拍”，再调动作、台词、画面【外部·可直接用】

**用法**：剧本定稿后、拆分镜表之前用，是从导演角度做的最后一轮微调。第一步只把“角色觉得 / 气氛变得紧张”这类拍不出来的句子改成看得见的动作，同时明确 OS/VO 属于正常的声音呈现，不要当问题改掉。第二步按节奏需要拆或合动作、延长或缩短台词、删掉没有用的画面。和 3.9（剧本删减）、3.11（独白与旁白规程）、3.18（AI 可拍性改写）配合用。

**来源**：[山音超级导演大师](https://github.com/Shanyin-ai/shanyin-director-master) director-master/references/core-methodology.md “剧本微调原则”和“叙事目的分析法”，MIT（作者要求保留 @山音 署名）。摘编。

**提示词正文**：

```
请对这一集剧本做导演微调。只改表达，不改故事。

【第一步：视听化修正（小手术）】
只改摄影机拍不到的内容：
- “他觉得 / 她感受到 / 他意识到……” → 改成可见的动作或表情；
- “气氛变得紧张” → 改成具体的环境变化或人物的身体反应。
以下是正常的视听语言，不要改：特效描述、内心独白和旁白（角色（OS）：……）、音效和配乐指示、字幕和画面文字。

【第二步：每场戏先问“为什么必须存在”】
逐场写出它的叙事功能（交代信息 / 立人物 / 推进或升级冲突 / 埋或回收伏笔 / 节奏呼吸点），每场一到三个。
找不到任何功能的场次，建议删除或合并。

【第三步：四个微调焦点】
1. 动作节奏
   - 情感重场：把笼统动作拆成多个具体小动作，给观众时间感受情绪。
     例：“她打开信，看完后放下” → 拿起信封、翻看背面、撕开、展开、视线下移、折好放回、手指在信封边缘停一下。
   - 过场：把碎步动作合成一个干脆动作。
     例：“他站起来，走到门口，打开门，走出去，关上门” → “他起身出门。”
2. 台词
   - 关键情感节点可以延长：加犹豫、重复、岔开，让“说不到点上”本身成为表演；
   - 冗长解释压成一个词或一句话，必要时删掉台词，用沉默代替；
   - 改得更口语、更贴人物此刻的情绪，但信息不变；
   - 调断句：“我不想……走”和“我——不想走”节奏不同，每个断句都是可能的切镜点。
3. 画面
   - 情感重场可以加细节表演（例：听到坏消息先笑了一下，再崩溃）；
   - 既不推进情节、也不传递情感、也不建立氛围的画面，删掉；
   - 同一个目的有两种画面可选时，选视觉冲击更强的。
4. 呼吸点
   不要把所有安静时刻都压掉，保留必要的停顿场。

【不做的事】
不改核心戏剧动作，不改人物弧光方向，不加新的主要角色或情节线，不把旁白、OS、特效、字幕当成“不可拍”去改。

【输出】
按场列出：原句 → 改后 → 理由（属于哪一步、哪个焦点）；最后列出建议删除或合并的场次。
```
