## 5.1 角色参考四件套（主设定 / 表情 / 角度 / 姿态）【外部·仅参考】

> **实测（10/30）：无明显提升。** 生产中本来就关联角色、场景素材并用提取尾帧，变脸和场景跳变基本不出现。仅作参考。

**用法**：开拍前为每个主要角色建档，保证生成视频时人物不「变脸」。原文强调这是第一步：没有这套参考，角色在场与场之间会变样，这是 AI 视频的头号问题。

**来源**：收集人提供的 script_writer_prompt.md，节选翻译，许可不明。

**提示词正文**：

```
请为剧本中每个主要角色（包括新出场角色）输出以下四张参考表：

【一、主设定表】
角色名 / 首次出场 / 年龄 / 身高 / 体型与体态 / 肤色与肤质、明显标记 / 脸型 / 眼睛（颜色、形状、神情）/ 鼻 / 嘴唇 / 发型发色 / 显著特征（疤痕、痣、纹身等）/ 声音（性别、年龄感、音色、口音）/ 性格的外在表现（站姿、手势、表情习惯）/ 默认服装（面料、颜色、版型、新旧）/ 场景服装变体

【二、表情表】（每种情绪写具体的面部变化和镜头可见线索，不只写情绪名）
恐惧 / 愤怒 / 希望 / 疲惫 / 坚定 / 绝望 / 麻木 / 剧情需要的其他情绪
例：愤怒——咬紧下颌、眉头紧锁、鼻翼张开、眯眼；可见线索：太阳穴青筋、皮肤泛红、身体僵直

【三、角度表】
正面 / 左侧面 / 右侧面 / 左四分之三 / 右四分之三 / 俯视 / 仰视——每个角度写外貌特征和辨识要点

【四、姿态表】
自然站立 / 走路 / 跑步 / 坐 / 跪 / 伸手 / 剧情特有姿态——每种写身体描述和轮廓特征

【五、角色持续状态】（逐场更新）
默认位置 / 默认姿态 / 默认情绪基线 / 默认服装状态 / 常带道具 / 动作特征（步态、速度、手势）/ 身体限制（伤病等）/ 行为习惯（眼神接触、个人距离）
每场结束时记录退场状态；下一场默认继承，除非剧情明确改变。
```
