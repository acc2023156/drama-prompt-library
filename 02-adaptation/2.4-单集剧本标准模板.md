## 2.4 单集剧本标准模板（含本集物证、结算、断章）【外部·可直接用】

**用法**：写单集前，让 AI 先填完「集头信息卡」再写正文。和 1.0 相比，多了几项 1.0 没有的硬约束：本集物证、质疑者配角、主角主动目标、本集结算、时长倒推。可以和 2.1 一起用：2.1 管格式，这条管戏。

**来源**：[short-drama-factory](https://github.com/lixiaoxiao9888-create/short-drama-factory) templates/episode-format.md 与 SKILL.md，MIT（收集人提供）。摘编：去掉了机检编号（E1~E26），保留规则本身。原模板用「△」标动作，这里统一改成我们用的「▲」。

**提示词正文**：

```
请按以下模板写第【XX】集。先填集头信息卡，再写正文。

第【XX】集：【集名/核心爽点标签】
【黄金前3秒钩子】：六母型之一（生死绝境/极端羞辱/身份暴涨/物证背叛/规则悬念/萌系治愈反差）
【冲突形态】：对话型 / 行动坚持型 / 身份错位型 / 关系情感型 / 规则谜题型 / 混合
【情绪流变】：A ➔ B ➔ C ➔ 绝命断章
【本集物证】：1~2 个贯穿本集的物件（碗/账本/群聊截图/到账页等，特写好拍，情绪落在物证上）
【质疑者配角】：本集替观众说狠话、发问的人（无则填“无”）
【对手要什么】：反派本集的即时目标和筹码
【本集主角主动目标】：主角本集要做的选择或行动（不能只是被动挨打）
【本集改变了什么】：信息/关系/资源/位置/危险，至少一项可见变化
【本集结算】：主角本集的可见反将 + 反派为本次施压付出的可见代价
【本集时长】：__ 秒（按“纯台词字数 ÷ 4.5 字/秒 + 动作行时长 + 留白”倒推，不许虚标）

[场景]：内景/外景・地点・日/夜（全集不超过 2 个场景）
[人物]：名（状态标签）、名（状态标签）

▲ 特写/中景：只写镜头拍得到的强视觉动作。
角色名（画面词｜语气词）：台词。

写作规则：
1. 强画面支撑：每 2~4 句对白必须穿插 1 条 ▲ 动作行，连续纯对白不超过 6 行。每条 ▲ 必须命中三类之一：①物理结果与视觉奇观；②身份反差与手头忙活；③物证亮牌与肢体对抗。不许单写“眼神微动”“微微一怔”“推了半寸”这类拍不出效果的微动作。
2. 神态短语用“画面词｜语气词”：摄像机拍得到的写在左边（如“一把推开主刀”），麦克风录得到的写在右边（如“厉喝”）。
3. 快慢变速：每场对白交替使用 3~6 字快刀句和 8~16 字大白话算账句；单句一口气不超过 25 字。
4. 大白话直给：凡亮出物证，同一轮对话里必须用大白话说出结论；凡出现专业术语或设定词，当句翻译成后果（多少钱、判几年、谁死谁活）。
5. 内心独白最多 1 处、不超过 25 字，只写“具体的账”，不交代设定；旁白最多 1 处、不超过 12 字；开头 3 秒和断章处禁用。
6. 结尾单列：【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）
```
