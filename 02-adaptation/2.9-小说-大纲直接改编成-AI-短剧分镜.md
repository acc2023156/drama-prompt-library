## 2.9 小说 / 大纲直接改编成 AI 短剧分镜（本集引擎 + 六节拍 + 时长分配）【外部·可直接用】（适用 Grok 等直接出分镜的流程）

**用法**：有的项目不走“剧本 → 分镜表 → 6.0”，而是从小说片段或分集大纲直接出分镜提示词（比如“大纲 → 分镜提示词 → Grok”）。这条就是给这一步用的：先用一句话锁定本集引擎，再排六个节拍，按比例分时长，最后逐镜写时间码。走剧本流程的项目，也可以拿前两部分来检查分集大纲。成人线的具体写法不在这里，按各项目自己的要求和《成人线与全年龄线分开原则》。

**来源**：[muxia0396/novel-to-ai-short-drama-skill](https://github.com/muxia0396/novel-to-ai-short-drama-skill) references/adaptation-workflow.md，MIT（11/05 整理人新增到收集页面）。摘编：去掉了多集全局地图之外的重复说明。

**提示词正文**：

```
请把下面的小说片段 / 分集大纲改编成一集 AI 短剧的分镜。单集成片时长：___秒（没给时长先问，不要开始）。

【一、先建事实账本（内部用）】
人物：身份、欲望、恐惧、当前认知、关系、说话习惯；事件：起因、行动、阻碍、结果、后果；秘密：谁知道、谁不知道、何时暴露；时空：地点、时间、前后顺序、移动关系；连续物：服装、伤势、道具、证据、环境状态；情绪：进入场景的状态、触发点、离开场景的状态。
素材分三类：原文事实（不得无故改变）；合理外化（把原文已有的心理或信息变成动作、对白、声音或道具证据）；改编新增（为压缩、转场或可视化加的连接内容，不能反转人物动机和因果）。
优先保留：核心因果、人物欲望、关系变化、关键伏笔、标志性动作和台词、不可替代的情绪峰值。优先压缩：重复说明、同功能配角、没有结果的往返、只提供氛围不推进剧情的段落。

【二、一句话本集引擎】
当【触发事件】发生，主角为了【可见目标】采取【行动】，却遭遇【阻力】，导致【不可逆变化】，并留下【下一步问题】。

【三、六个节拍】
1. 开场画面：第一帧或第一声就给出异常、冲突、欲望或危机；
2. 最小定向：用最少信息回答“谁、在哪、现在要什么”；
3. 压力升级：阻力必须改变主角的行为，不能只是重复争吵；
4. 转折：新信息、关系变化、选择或失败改变行动方向；
5. 高潮 / 释放：兑现本集承诺；
6. 尾钩：从高潮的结果自然长出，不用和本集无关的突发噱头。
每一场结束时至少改变一项：信息、权力、关系、风险、目标、位置或资源。没有变化的场景删掉、合并或改写。

【四、时长分配（起点，不是公式）】
钩子 0%~8%；定向 8%~22%；升级 22%~65%；转折 / 高潮 65%~90%；余波 / 尾钩 90%~100%。
镜头规模参考：15~30 秒 1 场 4~8 镜；31~60 秒 1~2 场 8~14 镜；61~90 秒 1~3 场 12~20 镜；91~180 秒 2~4 场 18~30 镜。不要为了凑数硬切。
台词语速估算：克制、停顿多约 2.5~3.2 字/秒；日常清晰 3.3~4.2 字/秒；争执、快节奏 4.3~5.0 字/秒（不宜整集维持）。对白之外另计反应、动作完成、观众理解信息的停顿。
先逐镜写“时间码 + 持续秒数”，各镜相加必须等于目标时长。超时先删重复信息和没有变化的反应；不足时加有意义的反应、悬念停顿或因果步骤，不注水。

【五、文学语言外化】
她开始怀疑他 → 视线停在矛盾证据上，收回伸出的手，删掉没发出的消息；
他非常愤怒 → 指节压白，杯中水震动，短促呼吸后改变行动；
多年过去 → 同构图匹配剪辑，道具磨损，季节或空间变化；
他身份尊贵 → 别人让路、称呼变化、权限行为、站在空间中心；
她想起往事 → 声音桥、闪回碎片、触发物特写；只在确有必要时用旁白。
旁白只承担画面和对白难以表达的主观层、时间跨度或叙事风格，不解释观众刚看见的动作。

【六、多集时】
先列每集的目标、阻力、核心变化、主导情绪、开场钩子、尾钩；每集都要有阶段性收益，不能连续几集只铺垫；尾钩由本集的选择或结果产生，下一集开场尽快兑现或有意义地改写这个预期。
```
