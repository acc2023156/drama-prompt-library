## 5.3 场次连续性状态表【外部·仅参考】

> **实测（10/30）：不推荐。** 条件过于复杂，可能让视频模型理解出现偏差；效果和 agent 自动描述差别不明显。

**用法**：连续生成多场戏时，每场结束让 AI 输出一次状态表，下一场以此为起点，避免道具「瞬移」、伤口消失、衣服换色。

**来源**：收集人提供的 script_writer_prompt.md，节选翻译，许可不明。

**提示词正文**：

```
每写完一场，请输出「第 X 场结束后的连续性状态」，作为下一场的默认起点（除非剧情明确改变）：

时间：时段 / 天气 / 时间推进了多久
人物（逐个）：位置 / 朝向 / 姿态 / 服装状态 / 身体状态（受伤、湿、脏、疲惫）/ 情绪状态 / 随身道具 / 退场动作
道具（逐个）：名称 / 归属 / 位置 / 状况
环境：地点 / 光线状态 / 氛围状态 / 环境变化
镜头：结束景别 / 机位 / 方向
转场：继承的元素 / 改变的元素 / 转场意图
另外记录：观众已经知道什么、角色知道什么、已经揭示了什么、哪些情绪后果要延续。
```
