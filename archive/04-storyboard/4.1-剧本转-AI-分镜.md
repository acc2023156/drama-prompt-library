## 4.1 剧本转 AI 分镜：单镜三行模板【外部·可直接用】

> **实测（10/30）：不推荐用于 X-tasy。** 条理清楚，但不如直接让 momo agent 根据分镜脚本出分镜提示词；模板里没有关联画布素材的部分，和素材条件冲突，出片不符合要求。详见《提示词测试反馈汇总20261030》。

**用法**：剧本定稿后生成分镜。先发「单镜规范」，再按「调用模板」贴剧本。它的强项是动作四段式和空间量化（标出人物间距、动作幅度），能减少人物重叠、动作僵硬。可以接在 1.0 的「▲」动作处理之后用。

**来源**：[script-to-storyboard](https://github.com/nhanhxxm2can9351-glitch/script-to-storyboard) templates 目录，MIT。

**提示词正文**：

```
【单镜规范】每个分镜严格按三行输出：

第1行（加粗）：分镜X 分镜名称（起始时间-结束时间）
  示例：分镜17 神丹到手（00:46.5-00:52）
第2行：【景别】，【机位角度】，【镜头运动：运动方式+跟随主体+运动节奏+衔接方式】，【剪辑约束：无跳切/无卡顿/无缝衔接】，动态模糊强度：低/中/高：
  人物站位与空间关系 + 完整动作时序（预备→发力→中途→收尾） + 动作次生物理效果 + 人物神态视线细节 + 环境联动表现
第3行（斜体）：台词 / OS / 系统语音：对应内容
  无台词时：台词 / OS / 系统语音：无（同期声：xxx 音效）

镜头参数可选值：
- 景别：大远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写
- 机位角度：平视 / 微仰 / 低机位仰拍 / 微俯 / 高机位俯拍 / 主观视角
- 镜头运动：推 / 拉 / 摇 / 移 / 跟随 / 环绕 / 手持微晃 / 固定机位（必须绑定主体与节奏）
- 剪辑约束：无跳切 / 无卡顿 / 无缝衔接 / 承接上一分镜姿态
- 动态模糊：低 / 中 / 高

动作时序四段式（必须完整）：
- 预备：动作起始姿态（江枫右手撑地、小臂肌肉绷紧）
- 发力：力量发出过程（腰腹发力卷身而起、道袍下摆扬起）
- 中途：动作过渡状态（单膝离地过渡至双脚踏实地面）
- 收尾/定格：动作结束姿态（直立定格、双肩打开、下颌微抬）

空间量化要求：标注人物间距（如“两人面部间距约25cm”）、动作幅度（如“右脚后撤约40cm”）、物体尺寸、特效范围。

次生物理效果（至少选配一项）：尘土 / 光晕 / 衣料褶皱 / 光影变化 / 气流扰动 / 纱帐鼓荡 / 粒子飞散 / 冲击波纹 / 水雾 / 碎石飞溅

节奏：剧情和动作段单镜 1.5~2.5 秒，情绪、特效、收尾镜头 3~5 秒。

负面排除项（全局强制）：杜绝游戏CG感、禁止动作迟钝僵硬、禁止逻辑混乱、人物无变形无穿模、无字幕无水印

【调用模板】
剧本：[剧本全文]
要求：单集总时长 XX 秒，XX 题材，XX 风格，资产 ID 预留
特殊画质要求（选填）：如 ARRI ALEXA Mini LF，青橙色调，手持跟拍
```
