## 7.1 合规红线 11 条 + 敏感词替换表【外部·可直接用】

**用法**：剧本写完后做合规自检，把这段和剧本一起发给 AI。比 1.0 里「绝对不能有关于警察执法、政治、色情、血腥暴力、外国角色、抽烟等违禁元素」那一句细得多，还附了替换词。注意：这是全年龄线的标准，成人线另按「成人线与全年龄线分开原则」处理。

**来源**：[short-drama-factory](https://github.com/lixiaoxiao9888-create/short-drama-factory) references/screenplay-compliance-rules.md，MIT（收集人提供）。摘编。原文称依据「广电 16 号令及 2026-06 专项治理」，具体政策条文我没有逐条核对，正式使用前建议和平台最新审核规则对一下。

**提示词正文**：

```
请对照以下红线逐条审查剧本，列出所有命中的位置（第几集/第几场/哪一句）、命中哪一条，并给出合规改写。

一票否决红线：
1. 政治性有害内容：危害国家统一/主权、泄露国家秘密、损害国家荣誉。
2. 暴力复仇/私刑：主角不得以暴制暴、私自处决反派；惩恶可用商业制裁、揭露真相、正当防卫，最终刑事责任交给公安和司法机关。
3. 封建糟粕/纯迷信真鬼：禁八字合婚、冥婚、跳大神；民俗恐怖要走“民俗解谜/非遗志怪”包装，落点是人为或心理悬疑。
4. 低俗色情：禁露点、性暗示镜头、露骨台词、软色情擦边。
5. 毒品/赌博：禁展示吸毒制毒细节、赌博出千手法。
6. 丑化军警公职：警察、法官、检察官、军人不得塑造成反派或贪腐者；不得出现“买通法官”“官匪勾结”。
7. 歪曲历史/民族宗教：禁美化侵略、破坏民族团结、亵渎宗教。
8. 拜金炫富：禁宣扬“金钱万能”“嫁入豪门即人生胜利”；奢华元素只能作为反派丑态或主角伪装，终局导向勤劳、正义。
9. 未成年人不良引导：禁未成年人吸烟饮酒、校园霸凌、早恋美化；未成年角色不参与暴力复仇主线。
10. 个人隐私：禁出现真实身份证号/手机号/住址/车牌；禁把“全网人肉”当爽点。
11. 其他违反公序良俗：出轨合法化、虐待动物、畸形婚恋观等。

节奏自查：反派恶行（造谣、虐待、侵占、构陷）不得超过 3 集仍未遭到任何反击或惩治。
动作戏写法：用“受力震飞、骨裂声响、制服倒地”等写意手法，不写断肢见血。

敏感词替换：
- “杀了他 / 要你的狗命 / 灭门” → “废了他 / 让你付出代价 / 让他受到法律制裁 / 送他进铁窗”
- “黑社会 / 堂口 / 砍人” → “地下商会 / 暗处势力 / 地痞恶霸”
- “买凶杀人” → “雇佣打手制造麻烦”
- “我要弄死他” → “我让他跪着把账还清楚 / 我要他当众身败名裂”
- “这鬼真的索命来了” → “这老宅里的传说原来是有人装神弄鬼”
- “行贿 / 买通法官” → “不正当利益输送 / 违规商业勾结”
- “泼硫酸 / 割喉” → “打落手腕 / 夺下凶器 / 当场制伏”
- “老太婆去死” → “你休想再颠倒黑白”
```
