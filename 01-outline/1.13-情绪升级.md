## 1.13 情绪升级：六层拉扯 + 后悔流双曲线 + 延迟满足 + 禁止翻旧账【外部·可直接用】

**用法**：编辑常说“情绪不够”“冗长啰嗦”时用，适合写分集大纲和卡点集之前。核心三条：冲突要一层比一层狠，每层带新信息；大卡点前铺多层递进的小冲突；后悔流里男主的后悔要一直拖到结局前才彻底爆发。和 1.10（爽点公式）的区别：1.10 讲单个爽点怎么设计，这条讲一串冲突怎么往上叠。

**来源**：[艾玛短剧 · 编剧 Skills](https://github.com/adoria111/emma-screenwriting-skills) advanced/story-writing/skills/em-chief-writer/references/writing-rules.md “情绪升级”一节，MIT（11/11 整理人新增到收集页面）。摘编：保留规则和模板，去掉了交叉引用。作者说明“六层”“三层”等数字是特定类型的参考，不是硬性要求。

**提示词正文**：

```
请按以下规则检查（或设计）这部剧的情绪升级。

【一、逐层升级：轻度 → 中度 → 重度】
反派或家人的态度和行为越往后越过分，每个新事件更狠、更戳心。
例（家庭逆袭）：偏心不分钱（轻）→ 连 3 千都不肯借（中）→ 把 1.5 万存款借给外人娶媳妇（重）。
两条升级线同步往上走：
- 打压 / 后悔线：看不起 → 开始后悔但嘴硬 → 彻底悔恨求饶；
- 事业 / 反击线：数字看得见地变大（打工赚 4 万 → 开网店赚 100 万 → 生意做到上亿）。
长剧靠“故事点”续航：约 70 集安排 3 个大故事点，80 集再加一层。

【二、六层拉扯：大卡点前铺 6 个层层递进的小冲突】
每个都比前一个更激烈，每个都带新信息或新的冲突方式；吵完一个就过去，进入下一个。
模板（家宴前）：① 身份打压（“你没资格参加宴会”）→ ② 上升到肢体（要动手）→ ③ 新人物介入激化（男主不分青红皂白护着对方）→ ④ 颠倒黑白（女主的功劳给了女配）→ ⑤ 抢走重要物品（妈妈的遗物）→ ⑥ 逼下跪后出尔反尔（跪了，对方还是摔了遗物，到顶点）。
层级走向：骂人 → 推搡 → 毁坏重要物品 → 牵连亲人。是递进，不是并列。

【三、禁止翻旧账】
- 每个新事件都要更激烈、带新的信息点；不要在同一层面重复冲突。
- 不靠反复回忆旧委屈凑情绪；旧委屈用闪回，集中堆在卡点集里升华。
- “冗长啰嗦”的根因，就是反复强调反派有多过分，却没有新进展。

【四、后悔流双曲线（感情线和事业线方向相反）】
- 女主：感情起点高（深爱）→ 经历矛盾一路下滑；同时事业 / 自我意识线上升。
- 男主：感情起点低（冷淡）→ 随着女主感情下滑、事业上升而缓慢上升；女主触底决心离开时才真正觉醒。
- 两条线在矛盾激化点交叉，这里就是关键卡点。
- 事业成功不只是打脸，也是让男主刮目相看、感情升温的催化剂。女主事业成功后仍会在意“他为什么还这样对我”，这种纠结才真实。

【五、延迟满足】
- 观众要的不只是打脸，还有把委屈说出来，并看到对方后悔和认可。
- 女主的付出和委屈用具体的日常细节（“我每天五点起床做饭，你吃过一次吗？”比讲道理更有共鸣）。
- 男主不能很快后悔，要一点点积累，大结局前才彻底爆发。
- 用两个交替的悬念维持张力：男主什么时候发现女主要走？女主什么时候真的离开？

【六、人设是可信的矛盾体，不是脸谱】
纯粹的坏人（又穷又丑又家暴）不如贴近现实的矛盾体（“我爱你，但我妈不同意”）。反派“又当又立”更能引发代入和愤怒。

【自检】
- 每个新冲突比上一个更狠，且有新信息，没有翻旧账；
- 大卡点前铺了多层递进拉扯；
- 后悔流的感情线下滑、事业线上升，在卡点交叉；
- 男主的后悔拖到结局前才彻底爆发；
- 女主的委屈用了具体日常细节，不是空喊；
- 反派态度是轻 → 中 → 重升级；
- 人设是可信的矛盾体。
```
