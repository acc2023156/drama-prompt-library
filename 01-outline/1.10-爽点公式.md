## 1.10 爽点公式：消极情绪 × 烈度放大 × 信息差打脸【外部·可直接用】

**用法**：立项、写分集大纲时，用这条设计每一个爽点：先找观众最有共鸣的委屈，再按五种手法把委屈放大到合适的烈度，最后用信息差安排打脸的时机。后半部分是常见主题（离婚、赘婿、战王、神医、重生等）的情绪曲线，选题时可以直接对照。和 1.3、1.4 的区别：那两条管节奏和断章，这条管“爽”从哪里来。

**来源**：[oiuv/ai-short-drama](https://github.com/oiuv/ai-short-drama) skills/drama-script/references/satisfaction-model.md、theme-patterns.md，MIT（11/07 整理人新增到收集页面）。摘编：主题部分只保留情绪曲线，删去了经典套路的举例句。

**提示词正文**：

```
请按“爽感 = 消极情绪 × 烈度放大 × 信息差打脸”设计（或检查）下面这部剧的爽点。

【第一步：找消极情绪】选最能引发大众共鸣的一种，越普遍越好：
- 被轻视：能力被质疑、身份被嘲笑；
- 被背叛：伴侣出轨、朋友背刺；
- 被欺负：职场霸凌、家族排挤；
- 被误解：好心被当成驴肝肺；
- 被剥夺：利益被抢、成果被窃取。

【第二步：放大烈度】五种手法：
1. 身份反差：不是被同事看不起，而是被自己带出来的徒弟当众羞辱；
2. 场合升级：不是私下被骂，而是公司年会上被当众开除；
3. 利益绑定：被欺负的同时，家人或爱人也受牵连；
4. 时间累积：忍辱负重十年，今天被当众揭穿；
5. 落井下石：被打压之后，对方还要斩草除根。
烈度五级：1 私下被欺负 → 2 当众被羞辱 → 3 重要场合被打压 → 4 家人或爱人受牵连 → 5 生死存亡关头。

【第三步：信息差打脸】观众知道的比角色多，才有期待：
- 身份信息差：观众知道主角是大人物，反派以为他是废物；
- 能力信息差：观众知道主角有金手指，反派以为他靠运气；
- 关系信息差：观众知道主角和大佬有关系，反派以为他没靠山；
- 未来信息差（重生类）：观众知道主角知道未来，反派以为是巧合。
打脸时机：即时打脸（小反派、日常冲突，快速爽）；延迟打脸（大反派、高潮，积累期待）；多次打脸（重要反派、多集剧情，持续爽）。

【组合模式】层层递进：小打脸 → 中打脸 → 大打脸 → 终极打脸；连环打脸：反派 A 被打脸 → 反派 B 跳出来 → 再被打脸；追悔莫及：被抛弃 → 主角成功 → 对方后悔 → 求复合 → 被拒绝。

【常见主题的情绪曲线】
离婚：被嫌弃 → 被羞辱 → 被抛弃 → 身份曝光 → 追悔莫及
赘婿：被轻视 → 被羞辱 → 家族危机 → 挺身而出 → 身份揭露
霸总：被看轻 → 契约关系 → 逐渐沦陷 → 身份揭晓 → 宠爱打脸
战王：隐忍 → 被欺负 → 触及底线 → 爆发 → 降维打击
金手指：底层挣扎 → 获得能力 → 初试牛刀 → 能力升级 → 碾压
暴富：穷困潦倒 → 被羞辱 → 突然暴富 → 打脸 → 众星捧月
神医：被质疑 → 被羞辱 → 危急病人 → 出手救人 → 震惊全场
家族：被排挤 → 被赶走 → 独立奋斗 → 功成名就 → 归来碾压
重生：前世惨死 → 重生节点 → 提前布局 → 仇人入套 → 复仇成功

【注意】
1. 爽点密度要高，不能让观众等太久；
2. 消极情绪不能持续太长，否则观众会烦；
3. 打脸力度要和之前的欺负程度匹配，欺负越狠，打脸越狠；
4. 始终保持观众的上帝视角，不要让观众和主角一起蒙在鼓里。

【输出】逐个爽点列出：消极情绪｜烈度手法和等级｜信息差类型｜打脸时机｜所在集数。
```
