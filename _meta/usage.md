## 使用说明

- **格式沿用《提示词1.0》**：每条都是「编号 · 名称 → 用法 → 提示词正文」。正文放在灰色代码框里，整段复制给 AI 即可。
- **按生产流程排序**：一、立项与大纲 → 二、小说转剧本 → 三、剧本修改与精修 → 四、分镜 → 五、角色与场景设定 → 六、视频生成 → 七、合规。
- **来源标签**（每条标题后面都有）：
  - 【内部 1.0】内部团队整理的《提示词1.0》，原文照录。
  - 【外部·可直接用】来自 MIT 等开源许可的 GitHub 仓库，可以复制、修改、商用，只需保留出处。
  - 【外部·仅参考】许可不明或作者限制使用，内部学习可以，不建议原样写进正式 SOP。
- **实测情况**：11/03 第二轮，6.4、6.9、6.11、6.12、6.7、3.9、3.11、3.12 已并进视频专用提示词 6.0 用于生产。10/30 测了视频端（4.1、4.2、5.1~5.4、6.3、6.4），结论标在各条下方，推荐的只有 6.3 + 6.4。剧本端和其余条目还没测，建议下一轮先测剧本端：3.3 台词七维、3.6 五席圆桌审核、3.8 去 AI 味、3.11 独白与旁白规程。
- 标「摘编」的条目，是我把原仓库里给 Agent 用的规则文件压缩改写成了能直接粘贴的提示词，核心规则没有改动。
